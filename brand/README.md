# Бренд (временный)

Единственный источник названия продукта, знака, палитры и набора иконок (ADR-0011). Оба приложения
(`frontend/`, `admin/`) читают `brand.json`; сменить название или знак — одна правка этого файла.

- `name` — рабочее название; финальное выберет владелец до открытой беты (M5).
- `mark` — знак: скруглённый квадрат цвета `accent` и линии цвета `onAccent` (`strokes` — пути SVG).
- `palette` — цвета бренда для светлой и тёмной темы; из них и `tokens.json` строятся дизайн-токены.
- `icons` — набор иконок интерфейса: Lucide (`lucide-vue-next`), лицензия ISC.
- `reactions` — откуда графика реакций (ADR-0095): Fluent Emoji, вариант Flat (Microsoft), лицензия MIT. Сами SVG —
  в `reactions/`, по одному на код реакции, рядом текст лицензии `reactions/LICENSE`, который MIT требует сохранять.
  Приложения не держат файлов картинок (тест `brand.spec.ts`) и берут их отсюда.

Цвета и графика DTF не используются; тест `frontend/tests/brand.spec.ts` проверяет контраст (WCAG AA),
удалённость палитры от цветов DTF, лицензию иконок и то, что название нигде больше не записано.

## Дизайн-токены (ADR-0012)

- `tokens.json` — остальные роли цветов обеих палитр, шрифты, кегли, отступы, скругления, размеры, границы
  раскладок.
- `tokens.ts` строит из `brand.json` и `tokens.json` CSS-переменные; `tokens.css` — его результат, руками не
  правится. После правки JSON выполните `pnpm test -u` в `frontend/` — тест перепишет `tokens.css`.
- `stylelint-rules.mjs` — правила линтера стилей обоих приложений: цвета и размеры только из токенов.
