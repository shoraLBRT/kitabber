# ADR-0041. Адрес поста: id и слаг из заголовка

- Статус: предложено (21 ноября 2026), задача E07-02 (#50); действует, пока владелец не решит иначе
- Требования: [spec.md](../spec.md#fr-post-пост) (FR-POST: «Адрес вида /тема/id-слаг; слаг строится транслитерацией
  заголовка»), [ui/post.md](../ui/post.md), [ui/topic.md](../ui/topic.md) (адрес темы `/<тема>`)
- Связанные решения: [ADR-0025](0025-blogs-subsite-and-profile.md) (адрес блога `/u/<никнейм>` или `/u/<UUID>`,
  открытый вопрос о коротком числовом номере), [ADR-0029](0029-post-model-and-api.md) (модель поста, UUID v7)

## Контекст

ТЗ задаёт адрес поста `/тема/id-слаг`. Пост живёт в личном блоге или в теме; у блога адрес `/u/<никнейм>`, у темы —
`/<тема>`. Идентификатор поста — UUID v7 (ADR-0029), короткого числового номера нет ни у поста, ни у блога (открытый
вопрос ADR-0025). Заголовок необязателен (короткий пост) и меняется при правке.

## Решение

1. **Адрес — `<адрес блога>/<id>-<слаг>`**: `/u/<никнейм>/<id>-<слаг>` в личном блоге и `/<тема>/<id>-<слаг>` в теме —
   одна схема, одна страница (`frontend/pages/post.vue`, путь и псевдоним в `definePageMeta`). `id` — UUID поста.
   Пост без заголовка (или без букв и цифр в нём) — `<адрес блога>/<id>`.
2. **Пост находится по id.** Последний сегмент адреса должен начинаться с UUID, за которым идёт конец или `-<слаг>`;
   поэтому страница поста не перехватывает другие адреса (`/u/<блог>/comments`, `/settings/blog`). Слаг и блог в
   адресе на поиск не влияют: если они не совпадают с каноническими (старый заголовок, лишний слаг, UUID блога вместо
   никнейма, другой блог, тема под `/u/`), сервер отвечает 301 на канонический адрес, в браузере — замена адреса.
3. **Слаг не хранится.** Его строит `PostSlug.From` модуля Posts из текущего заголовка, API отдаёт его полем `slug`
   у поста (`null` без заголовка). Правка заголовка меняет адрес, старые ссылки продолжают работать через п. 2. Клиент
   слаг не вычисляет — сравнивает адрес с тем, что собрал из `slug` и блога.
4. **Правила слага.** Нижний регистр; русские буквы — латиницей по таблице, близкой к адресам Яндекса и DTF
   (ж → zh, х → h, ц → c, щ → shch, й и ы → y, ю → yu, я → ya, ъ и ь пропадают), плюс і, ї, є, ґ, ў; у остальных букв
   снимаются диакритические знаки (é → e); всё, что не латинская буква и не цифра, разделяет слова, слова соединяются
   дефисом. Длина — не больше 60 символов, длинный слаг обрезается по последнему дефису, который помещается.

## Последствия

- Адрес длинный из-за UUID (36 символов). Если владелец решит ввести короткий числовой номер (вопрос ADR-0025),
  схема останется той же, а старые адреса с UUID можно будет перенаправлять на новые.
- Страницы темы `/<тема>` ещё нет (E11-01, #76): ссылка на тему со страницы поста заработает вместе с ней.
- Смена никнейма блога меняет адреса его постов; старый никнейм не ведёт на новый, пока это не решит E04-05.
- Отрисовка блоков на странице поста — E07-03 (#51); пока страница показывает текст текстовых блоков.
