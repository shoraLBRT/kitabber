# ADR-0103. «Поделиться» поста: системное меню телефона, список со ссылкой и соцсетями, каноническая ссылка

- Статус: предложено
- Дата: 2026-11-27
- Задачи: E07-07 (#97); опирается на [ADR-0041](0041-post-address-and-slug.md) (адрес поста),
  [ADR-0050](0050-post-header-and-action-panel.md) (панель действий), [ADR-0053](0053-post-actions-menu.md) (меню «…»,
  копирование ссылки), [ADR-0013](0013-ui-components.md) (`UiMenu`)

## Контекст

FR-POST: на плавающей панели поста есть «Поделиться». Критерии E07-07: на телефоне открывается системное меню, на
десктопе — список с копированием ссылки, ссылка каноническая. До задачи кнопка только копировала ссылку. Ограничения
проекта: никаких сторонних скриптов и виджетов «поделиться», которые грузят чужой код и следят за читателем.

## Решение

1. **Системное меню — на телефоне с Web Share API.** «Поделиться» вызывает `navigator.share({title, url})`, когда экран
   уже первой точки (`phoneQuery`, меньше 640 px, как у меню «…» поста) и у браузера есть `navigator.share`. Заголовок
   передаётся, только если он у поста есть. Закрытие меню (`AbortError`) ничего не говорит; любой другой отказ
   браузера копирует ссылку с тостом, как пункт списка.
2. **Список — везде остальное.** На широком экране (даже когда браузер знает Web Share API, как Safari на macOS) и на
   телефоне без API кнопка открывает `UiMenu` над собой (новый проп `side="above"`: панель прилипает к низу окна):
   «Скопировать ссылку», затем Telegram, ВКонтакте, X.
3. **Соцсети — простые адреса «поделиться»**, без кода с чужих сайтов: `https://t.me/share/url?url&text`,
   `https://vk.com/share.php?url&title`, `https://x.com/intent/post?url&text`. Пункт открывает адрес в новой вкладке
   (`window.open(…, '_blank', 'noopener,noreferrer')`): чужая страница не получает ни `opener`, ни `Referer`. Пустой
   заголовок в адрес не попадает. Набор сетей — список `shareNetworks` в `utils/share.ts`; другая сеть добавляется
   туда же с подписью в `i18n`.
4. **Ссылка каноническая.** `canonicalUrl(path, origin)` — origin сайта и путь канонического адреса поста
   (`postPath`, ADR-0041), без query и hash: делятся адресом поста, а не тем, как читатель на него пришёл. Им же
   пользуется «Скопировать ссылку» меню «…» (`copyPostLink`).
5. **Сервер рисует кнопку списка**, решение о системном меню принимается после монтирования (Web Share API и ширина
   экрана есть только в браузере).

## Последствия

- `components/post/PostShare.vue` — кнопка; `utils/share.ts` — ссылка, адреса сетей, пункты, выбор системного меню;
  `UiMenu` умеет открываться над кнопкой.
- Сторонний код не грузится; сеть получает ссылку и заголовок, только когда читатель сам выбрал её.
- Карточки ленты своей кнопки «Поделиться» пока не имеют; когда появится, она берёт тот же `PostShare` и
  `feedItemPath`.
