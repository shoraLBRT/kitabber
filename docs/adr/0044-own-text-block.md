# ADR-0044. Свой блок «Текст» вместо встроенного абзаца Editor.js

- Статус: предложено 22 ноября 2026, задача #331 (остаток E05-03, #38)
- Требования: [spec.md](../spec.md) (FR-EDITOR: превращение блоков без потери содержимого)
- Связанные решения: [ADR-0023](0023-block-schemas-and-html-cleaning.md) (разрешённая разметка),
  [ADR-0028](0028-text-block-formatting.md) (блок «Текст»), [ADR-0031](0031-heading-blocks-and-anchors.md)
  (заголовки)

## Контекст

Заголовок, превращённый в текст, терял жирный, курсив, маркер и ссылки. Причина — в Editor.js 2.31: встроенный
абзац объявляет `sanitize` по полям (`{text: {br: true}}`). При сохранении блока Editor.js читает такой конфиг по
полям, а при превращении другого блока в абзац (`BlockManager.convert`) и при слиянии разных блоков
(`mergeBlocks`) — как плоский список тегов. В этом списке есть только «тег» `text`, и вся разметка стирается.
Встроенный абзац не экспортируется, поэтому подменить ему один `sanitize` нельзя.

Варианты: патч Editor.js (`pnpm patch`) — правка чужой сборки, которую придётся переносить при каждом обновлении;
свой инструмент абзаца — около ста строк, в API Editor.js.

## Решение

1. Блок «Текст» — свой инструмент `TextTool` (`frontend/editor/text.ts`), подключённый под именем `paragraph`
   (`engine.ts`). Поведение — как у встроенного абзаца Editor.js 2.31: класс `ce-paragraph`, плейсхолдер из
   конфига, `preserveBlank`, вставка тегов `P`, слияние, очистка пустого абзаца по `Backspace`/`Delete`,
   превращение по полю `text`.
2. `sanitize` — плоский список: теги встроенных инструментов (`b`, `i`, `mark` из `MarkerTool`, `a` из `LinkTool`)
   и `br` — тот же список, что разрешает сервер (ADR-0023). Каждое правило — функция, возвращающая атрибуты тега:
   объектные правила Editor.js дополняет тегами инструментов как атрибутами, а функцию передаёт очистке как есть.
   Такой конфиг одинаково понимают сохранение, превращение и слияние.

## Последствия

- Заголовок → текст, цитата → текст и слияние заголовка с абзацем сохраняют разметку; критерий #38
  «преобразование текст↔заголовок сохраняет содержимое» выполнен в обе стороны.
- Перенос строки `<br>` при превращении в текст теперь сохраняется (раньше стирался вместе с разметкой).
- Новый инструмент разметки в панели текста нужно добавить и в `textTags`, иначе его теги будут стираться;
  модульный тест держит этот список.
- При обновлении Editor.js стоит сверить `TextTool` со встроенным абзацем новой версии.
