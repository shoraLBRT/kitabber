# ADR-0059. Правка и удаление комментария: окно правки, заглушка удалённого, меню «…» своих

- Статус: предложено (26 ноября 2026), задача E09-05 (#61); действует, пока владелец не решит иначе
- Требования: [spec.md](../spec.md#fr-comment-комментарии) (FR-COMMENT: редактировать в окне по времени, удалить;
  удалённые оставляют заглушку, если есть ответы), [docs/ui/comments.md](../ui/comments.md)
- Связанные решения: [ADR-0018](0018-openid-connect-provider.md) (токен остаётся на сервере сайта),
  [ADR-0048](0048-comment-tree-and-api.md) (дерево по материализованному пути), [ADR-0053](0053-post-actions-menu.md)
  (меню «…» поста, «своё» решает сервер сайта), [ADR-0054](0054-comment-tree-levels.md) (число ответов `replies`),
  [ADR-0056](0056-comment-form.md) (форма и отправка через сервер сайта)

## Контекст

Автор правит комментарий ограниченное время и удаляет его; удалённый с ответами остаётся заглушкой «Комментарий
удалён»; правленый помечен «изменено». Срок правки в ТЗ не назван. Дерево читается в браузере без токена
(ADR-0054), поэтому страница не знает, какие комментарии свои: `account_id` вошедшего на страницу не уходит
(ADR-0018, ADR-0053).

## Решение

1. **Окно правки — настройка `Comments:EditMinutes`**, по умолчанию 15 минут, от 1 до 1440; иное значение
   останавливает API при старте. Окно считается от `created_at` по `TimeProvider`; правка его не продлевает.
   Удалять можно в любое время. Менять и удалять может только автор; у гостевого комментария (FR-TG-6) автора на
   платформе нет — его не правит и не удаляет никто (модерация — E15).
2. **API.** `PATCH /api/v1/comments/{id}` `{ text }` — 200 с комментарием; после окна — 403
   `comments.edit_closed`, чужой — 403 `comments.not_author`, пустой или длинный текст — 400 `text`, удалённый или
   неизвестный — 404. Нужна подтверждённая почта, как для отправки (ADR-0020). `DELETE /api/v1/comments/{id}` —
   204; чужой — 403, повторно — 404; достаточно входа. `GET /api/v1/posts/{postId}/comments/mine` — `{ postId, ids }`,
   свои неудалённые комментарии под постом (нужен вход).
3. **Модель.** У комментария `edited_at` и `deleted_at` (миграция `EditAndDeleteComments`). В ответе — `editedAt`
   (для «изменено»), `editableUntil` (конец окна; `null` у гостевого и удалённого) и `deleted`.
4. **Удаление и заглушка.** Комментарий с ответами (на любой глубине) становится заглушкой: `deleted_at`
   ставится, текст стирается, в ответе нет автора и текста; место в дереве и число ответов остаются, ответить на
   заглушку нельзя. Комментарий без ответов удаляется из базы, и вместе с ним — каждая заглушка выше, у которой не
   осталось ответов: заглушка без ответов ничего не держит. Это делает чистая функция `CommentTree.Delete` над
   комментариями ветки, прочитанными одним запросом по корню пути. Текст удалённого не хранится.
5. **«Своё» решает сервер сайта.** После чтения дерева вошедшая страница спрашивает `GET /bff/own-comments?postId=`;
   сервер сайта зовёт `/comments/mine` с токеном сессии и отдаёт только идентификаторы. Отправленный комментарий
   становится своим сразу. Правка и удаление идут так же: `PATCH /bff/comments` `{ id, text }` (ответ — исход формы,
   как у отправки) и `DELETE /bff/comments?id=` (статус API как есть).
6. **Клиент.** У своего комментария — меню «…» (UiMenu на широком экране, нижняя шторка на телефоне):
   «Редактировать», пока `editableUntil` в будущем (время сверяется раз в 30 секунд), и «Удалить» с подтверждением
   «Удалить комментарий?». Правка открывает текст в форме на месте; отказ сервера (окно вышло) остаётся под полем с
   написанным текстом. Удаление меняет дерево так же, как сервер (`withDeleted`): заглушка над ответами или
   комментарий пропадает вместе с опустевшими заглушками выше. Рядом со временем — «· изменено» с временем правки в
   подсказке. Заглушка — строка «Комментарий удалён» без аватара, автора и действий.

## Последствия

- Остальные пункты меню «…» комментария (скопировать ссылку, пожаловаться, заблокировать автора; автору поста —
  закрепить, удалить ветку) добавляют их задачи в `commentMenuItems` (`frontend/utils/comment-menu.ts`); пока у
  чужого комментария меню нет.
- История правок не хранится: виден только факт и время последней правки.
- Срок в 15 минут — предложение, требует подтверждения владельца; меняется настройкой без новой сборки.
