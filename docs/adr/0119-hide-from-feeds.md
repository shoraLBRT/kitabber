# ADR-0119. Скрытие темы и поста из лент

Статус: предложено (E11-07, #112). Требования: FR-TOPIC («скрытие темы из лент»), FR-SUB («список скрытых тем,
скрытие отдельного поста»), [ADR-0089](0089-my-feed.md) (исключения читателя), [ADR-0091](0091-black-list.md)
(чёрный список, применение исключений после общего кэша).

## Контекст

Ленты уже умеют исключать то, что называет любой зарегистрированный `IFeedExclusionSource`: скрытые посты
(`FeedExclusions.Posts`), скрытые блоги и темы (`FeedExclusions.Blogs`) и заблокированных авторов. Источник
заблокированных есть (ADR-0091); источника скрытых постов и тем не было, как и действий «Скрыть» и списка в
настройках.

## Решение

1. **Где живут списки.** В модуле Preferences, рядом с чёрным списком: таблицы `preferences.hidden_posts`
   `(owner_account_id, post_id, hidden_at)` и `preferences.hidden_topics` `(owner_account_id, blog_id, hidden_at)`,
   ключ — пара. Внешних ключей в чужие схемы нет. При удалении аккаунта (`account.deleted`) его списки стираются.
2. **API** — `/api/v1/preferences/me/hidden`: `GET` отдаёт оба списка, последний скрытый первым, с названиями и `max`;
   `PUT` и `DELETE /posts/{postId}` и `/topics/{blogId}` идемпотентны (`204`); `GET /topics/{blogId}` —
   `{ hidden }` для кнопки на странице темы. Предел — **1000 постов и 1000 тем** (как у чёрного списка; предложение,
   требует подтверждения).
3. **Проверки через контракты.** Скрыть можно только опубликованный пост (`IPostDirectory.FindPublishedAsync`, иначе
   `404 preferences.post_not_found`) и только тему (`IBlogDirectory.FindAsync`: нет блога — `404
   preferences.topic_not_found`, личный блог — `400` по полю `blogId`). Личный блог из лент убирает чёрный список его
   автора (ADR-0091), отдельного «скрыть блог» нет. Названия для списка — `IPostDirectory.PublishedHeadlinesAsync` и
   `IBlogDirectory.CardsAsync` одним запросом на список; пост, который сняли с публикации или удалили, остаётся в
   списке с `gone: true`, чтобы его можно было вернуть.
4. **Ленты.** Тот же модуль регистрирует второй `IFeedExclusionSource` (`HiddenFromFeeds`): скрытые посты — в
   `Posts`, скрытые темы — в `Blogs`. Лента «Моя» исключает их в запросе, общие ленты — после кэша (ADR-0091); менять
   ленты не пришлось. Исключение одно: **лента самой темы** не убирает эту тему — человек открыл её страницу сам и
   видит её посты; скрытые посты и заблокированные авторы там по-прежнему убираются.
5. **Сайт.** «Скрыть» в меню «…» чужого опубликованного поста — только вошедшему, сразу, без подтверждения, с
   уведомлением «Пост скрыт из ваших лент…»; сама страница поста остаётся. Флаг `postHide` (E07-05) убран: пункт
   построен. На странице темы вошедший видит «Скрыть из лент» / «Показать в лентах» с пояснением; состояние читается
   в браузере после загрузки, до ответа кнопки нет. В «Приватность и блокировки» под чёрным списком — раздел «Скрытое
   из лент»: темы и посты со ссылками и «Вернуть в ленты», состояния «загрузка», «пусто», «ошибка» с «Повторить».
   Всё — через `/bff/hidden*`: токен человека есть только у сервера сайта (ADR-0018).

## Последствия

- Список скрытого — настройка человека и следует за ним на все устройства.
- На карточке ленты меню «…» ещё нет: скрыть пост можно со страницы поста; пункт в карточке появится с её меню.
- Общие ленты могут приходить короче `limit` (как и с чёрным списком, ADR-0091).
