# ADR-0026. Ядро блочного редактора на клиенте

- Статус: принято владельцем 21 ноября 2026 (предложено 21 ноября 2026), задача E05-01 (#35)
- Требования: [spec.md](../spec.md) (FR-EDITOR: блочный редактор; раздел 5: окно 800×700 px на десктопе,
  полноэкранный экран на телефоне), [docs/ui/editor.md](../ui/editor.md)
- Связанные решения: [ADR-0023](0023-block-schemas-and-html-cleaning.md) (формат документа и схемы блоков),
  [ADR-0012](0012-design-tokens.md) (размеры только токенами), [ADR-0013](0013-ui-components.md) (диалоги)

## Контекст

Задача требует редактор на базе Editor.js с общим с сервером форматом документа, отменой и повтором между блоками.
У Editor.js свой формат вывода (служебные `time`, `version`, `tunes`; список второй версии плагина — вложенные
`{content, meta, items}`), своей истории правок нет, а отмена браузера в `contenteditable` работает только внутри
одного блока. Типы блоков, меню блоков, черновики и публикация — отдельные задачи (E05-02…E05-10, #48, #49).

## Решение

1. **Движок — Editor.js 2.31** (`@editorjs/editorjs`, Apache-2.0), загружается динамическим импортом только в
   браузере. Компонент `BlockEditor` знает его через интерфейс `EditorEngine` (`frontend/editor/engine.ts`):
   сохранить, отрисовать, прочитать и поставить каретку, уничтожить. В компонентных тестах — фейковый движок.
2. **Модель документа** (`frontend/editor/document.ts`) — ровно формат ADR-0023: `{version: 1, blocks: [{id, type,
   data}]}`, поля `data` в порядке схемы. `toPostDocument` переводит вывод Editor.js (служебные поля отбрасываются,
   вложенный список разворачивается в плоский по порядку чтения, неизвестный тип — ошибка `UnsupportedBlockError`),
   `toEditorData` — обратно, с сохранением id блоков. Круговое преобразование без потерь проверяется тестом для
   всех типов версии 1. Пустой абзац сохраняется (`preserveBlank`), чтобы индексы блоков документа совпадали с
   индексами редактора.
3. **Отмена и повтор — снимками всего документа** (`frontend/editor/history.ts`): после каждого изменения (Editor.js
   сообщает о нём пачками, раз в 400 мс) документ сохраняется и записывается шагом вместе с кареткой (индекс блока
   и смещение в тексте). Ввод в одном блоке без паузы дольше секунды сливается в один шаг; добавление, удаление,
   перестановка блоков и правка другого блока — отдельные шаги. Отмена и повтор отрисовывают снимок и ставят
   каретку туда, где была правка. Перед отменой записывается ещё не сообщённая правка, поэтому она не теряется;
   эхо отрисовки (документ не изменился) шагом не считается. Предел — 100 шагов. Время — через внедряемые часы.
4. **Клавиши:** `Ctrl+Z` (`Cmd+Z`) — отменить, `Ctrl+Shift+Z` и `Ctrl+Y` — повторить; читаются по коду клавиши
   (`KeyZ`), поэтому работают в русской раскладке, и на уровне документа, пока фокус в окне редактора или нигде
   (во время отрисовки блоков). На телефоне и мышью — кнопки «Отменить» и «Повторить» в шапке окна.
5. **Окно** (`EditorWindow`): на десктопе диалог 800×700 px (токены `--size-editor-width`, `--size-editor-height`)
   по центру над затемнённой и размытой подложкой, кнопки «развернуть на весь экран» и «закрыть»; уже 640 px — весь
   экран с безопасными зонами, нижняя панель и «Написать» под ним. `Esc`, «✕» и подложка закрывают; `Esc` при
   открытом меню Editor.js закрывает меню. Адрес нового поста — `/write` (страница `frontend/pages/write.vue`).

## Последствия

- Плюс: формат клиента и сервера один; редактор отдаёт документ, который проходит проверку ADR-0023 без перевода
  на сервере.
- Плюс: история не зависит от плагинов блоков: новый тип блока получает отмену и повтор без своего кода.
- Минус: снимок — весь документ; для лонгридов M3 может понадобиться хранить разницу, а не копию (предел 100 шагов
  держит память ограниченной).
- Минус: отрисовка снимка пересоздаёт блоки; состояние внутри блока (например, открытое меню) при отмене
  сбрасывается.
- Каждый новый блок (E05-02…E05-06) подключает свой инструмент Editor.js и, если формат плагина отличается от схемы,
  переводит его в `toPostDocument` и `toEditorData` с тестом кругового преобразования.
