# Экран «Комментарии»

Требования: FR-COMMENT (дерево, сортировка, форма, действия, реальное время), FR-REACT (реакции и закладки на
комментариях), FR-MEDIA (вложения и GIF), FR-SUB (скрытые от заблокированных), FR-UI; раскладка —
[раздел 5 ТЗ](../spec.md#5-десктопная-и-мобильная-версии).

Комментарии показываются под постом ([post.md](post.md)) и на отдельной странице треда `/<тема>/<id>-<слаг>/comments/<id>`
(предложение, требует подтверждения). Ссылка на комментарий прокручивает к нему и подсвечивает его.

## Десктоп, 1440 px

```text
┌──────────────── колонка поста (--size-feed) ────────────────┐
│ Комментарии 48        [Популярные | По дате]                │
│ ┌ Комментарий… (свёрнутое поле) ────────────────────────┐   │
│ └────────────────────────────────────────────────────────┘   │
│ 📌 закреплённый комментарий автора поста                     │
│ (ав) Имя · 2 ч                                    [ … ]      │
│      текст комментария                                       │
│      ♥ 5 · Ответить · закладка                               │
│ │  (ав) Имя · 1 ч   ← ответ, отступ ветки --space-8          │
│ │       текст                                                │
│ │  │  (ав) …        ← линия ветки --color-border             │
│ │  └ Показать ещё 12 ответов                                 │
│ [−] свернуть ветку                                           │
└──────────────────────────────────────────────────────────────┘
```

- «Популярные | По дате» рядом с заголовком — группа из двух кнопок (`aria-pressed`), порядок веток под постом
  задаёт сервер (`?sort=popular|date`); «Популярные» по умолчанию — больше ответов выше (до рейтинга E10-05), «По
  дате» — новые сверху; ответы внутри ветки — в порядке дерева. Выбор помнится в браузере на все посты; при
  перечитывании и ошибке переключатель остаётся, у поста без комментариев его нет (E09-04,
  [ADR-0058](../adr/0058-comment-sorting.md); предложение, требует подтверждения).
- Форма сверху — свёрнутое поле «Комментарий…»; по нажатию раскрывается, показывает кнопки вложений (фото, видео,
  GIF) и «Отправить» (`--color-accent`). Форма ответа открывается под комментарием, на который отвечают («Ответить»;
  нет у гостевого комментария и на последнем уровне). Текст ждёт в черновике (localStorage, по форме), Ctrl+Enter
  отправляет, Escape закрывает форму ответа; гость вместо формы получает окно входа (E09-03,
  [ADR-0056](../adr/0056-comment-form.md); кнопки вложений — E09-10).
- Отступ уровня ветки `--space-8`, линии веток `--size-border` цвета `--color-border`; линия — кнопка «Свернуть
  ветку», свёрнутая ветка оставляет «Развернуть · N ответов». Первое чтение — 6 уровней; глубже — «Показать ещё N
  ответов» под последним показанным комментарием, подгрузка ещё 6 уровней на месте (E09-02,
  [ADR-0054](../adr/0054-comment-tree-levels.md); порог — предложение, требует подтверждения). «Продолжить ветку» на
  странице треда — E09-06.
- Новые с прошлого визита — полоса слева цвета `--color-accent`; пришедшие в реальном времени — счётчик «N новых»
  вверху блока, по нажатию вставляются.
- От заблокированных — строка «Комментарий скрыт» с «Показать»; удалённый с ответами — заглушка «Комментарий
  удалён» (`--color-muted`, без аватара, автора и действий) над ответами; без ответов удалённый пропадает (E09-05,
  [ADR-0059](../adr/0059-comment-edit-and-delete.md)).
- Меню «…»: ответить, скопировать ссылку, пожаловаться, заблокировать автора; своё — редактировать (в окне
  времени, 15 минут — предложение, требует подтверждения), удалить; автор поста — закрепить, удалить ветку. Сделано
  своё (E09-05): «Редактировать», пока не вышло окно, открывает текст в форме на месте («Сохранить», «Отмена»,
  Ctrl+Enter, Escape); «Удалить» спрашивает «Удалить комментарий?». Правленый помечен «· изменено» после времени,
  время правки — в подсказке. У чужого комментария меню пока нет.
- Текст `--font-size-md`, имя `--font-weight-medium`, время `--font-size-sm` `--color-muted`; аватар `--size-mark`.

## Телефон, 390 px

```text
┌──────────── 390 ────────────┐
│ Комментарии 48   [Попул. ▾] │
│ (ав) Имя · 2 ч       [ … ]  │
│   текст                     │
│   ♥ 5 · Ответить            │
│ │ (ав) ответ  ← отступ --space-4 │
│ │ └ Открыть ветку (12) →    │  глубокие ветки — отдельный экран
├─────────────────────────────┤
│ [Комментарий…]   [📎] [➤]   │  форма прижата к клавиатуре
└─────────────────────────────┘
```

- Отступ ветки уменьшен до `--space-4`; первое чтение — 3 уровня, глубже — «Показать ещё N ответов» по 3 уровня
  (E09-02, ADR-0054); отдельный экран ветки — со страницей треда E09-06 (порог — предложение, требует подтверждения).- Форма ответа прижата к низу экрана и к клавиатуре; нижняя панель вкладок скрыта, пока форма раскрыта.
- Меню действий и выбор реакции — нижние шторки, реакция по долгому нажатию.

## Состояния

### Пусто

- Нет комментариев: «Комментариев пока нет — будьте первым», форма раскрыта.
- Автор запретил комментарии или только подписчикам: вместо формы строка «Комментарии отключены автором» или
  «Комментировать могут подписчики автора» (FR-EDITOR, FR-PROFILE).

### Загрузка

- Скелетон трёх комментариев (круг аватара, две строки); подгрузка ветки — скелетон одной строки на месте «Показать
  ещё».
- Отправка: комментарий сразу появляется в дереве приглушённым (`--color-muted`, «Отправляется…», автор «Вы») до
  подтверждения сервера (E09-03, [ADR-0056](../adr/0056-comment-form.md)).

### Ошибка

- Дерево не загрузилось — блок ошибки с «Повторить» под постом, сам пост остаётся.
- Отправка не удалась — комментарий убирается из дерева, его текст возвращается в форму, под полем причина
  (`--color-danger`): «Не удалось отправить комментарий. Текст сохранён — попробуйте ещё раз.» или отказ сервера;
  закрытая форма ответа открывается снова (E09-03, ADR-0056).
- Окно редактирования истекло, карма ниже порога, лимит частоты — сообщение под формой с причиной (FR-REACT,
  FR-MOD); для правки: «Время на правку вышло: комментарий можно только удалить.», текст остаётся в поле (E09-05).
- Удаление не удалось — окно подтверждения остаётся, тост «Не удалось удалить комментарий».
- Потеря связи реального времени — тихое переподключение; новые комментарии подгружаются после него.

## Поведение и доступность

- Дерево — вложенные списки с `aria-level`; «свернуть ветку» — кнопка с `aria-expanded`.
- На десктопе `r` — ответить на выделенный комментарий (предложение, требует подтверждения).
