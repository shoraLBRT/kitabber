# Экран «Пост»

Требования: FR-POST (страница поста, действия, метки, версии), FR-REACT (реакции, закладка, репост, «Поделиться»),
FR-MEDIA (галерея), FR-COMMENT (комментарии под постом — [comments.md](comments.md)), FR-UI; раскладка —
[раздел 5 ТЗ](../spec.md#5-десктопная-и-мобильная-версии).

Адрес: `/<тема>/<id>-<слаг>` (FR-POST); пост в блоге без темы — `/u/<ник>/<id>-<слаг>` (предложение, требует
подтверждения). Сделано в E07-02 ([ADR-0041](../adr/0041-post-address-and-slug.md)): `id` — UUID поста, пост без
заголовка — `/<блог>/<id>`, неверный слаг или блог ведёт на канонический адрес (301).

## Десктоп, 1440 px

```text
┌──────────────────────────────────── шапка: [← назад] … ────────────────────────────────────┐
┌ левое меню ┐┌──────────────── пост (--size-feed) ─────────────────┐┌ правая колонка ┐
│            ││ аватар Автор · Тема · дата · метки       [ … ]      ││ Популярные     │
│            ││ Заголовок (--font-size-3xl)                         ││ комментарии    │
│            ││ блоки контента, ширина строки ≤ --size-measure      ││                │
│            ││ …                                                   ││ Интересные     │
│            ││ просмотры · репосты · «обновлён»                    ││ блоги          │
│            ││ Репосты и ответы (список)                           ││                │
│            ││ Комментарии (→ comments.md)                         ││                │
│            ││ Рекомендации под постом                             ││                │
│            ││   ┌ плавающая панель действий ───────────────┐      ││                │
│            ││   │ ♥ реакции · комментарии · закладка · ⇪   │      ││                │
└────────────┘└───┴───────────────────────────────────────────┴─────┘└────────────────┘
```

- Пост открывается в центральной колонке поверх ленты; в шапке появляется «← назад», возврат восстанавливает
  позицию ленты (раздел 5 ТЗ).
- Текст лонгрида: `--font-family-serif` или `--font-family-sans` по настройке, `--font-size-reading`,
  `--line-height-reading`, ширина строки не больше `--size-measure` (ADR-0012). Подзаголовки H2 — `--font-size-2xl`,
  H3 — `--font-size-xl`.
- Метки над заголовком: «из Telegram», соавтор, закреплённый, предупреждение модерации (`--color-warning`), «скрыт
  по требованию закона»; «обновлён» и «ещё дополняется» — рядом с датой, «обновлён» открывает историю версий.
- Плавающая панель действий прилипает к низу окна в пределах колонки ленты: реакции со счётчиком, комментарии,
  закладка, «Поделиться» (копия ссылки, соцсети), репост. Сделано в E07-04
  ([ADR-0050](../adr/0050-post-header-and-action-panel.md)): шапка с автором и панель «Нравится» (выключена до
  E10-01), «Комментарии» (якорь `#comments`), «Поделиться» (копия ссылки); остальное добавляют свои задачи.
- Меню «…» читателя: пожаловаться, скрыть, заблокировать автора, скрыть тему, скопировать ссылку, пост-ответ. Автора:
  редактировать, снять с публикации, удалить, закрепить в блоге, убрать тему, право комментирования, статистика.
  Пункта «продвинуть» нет (монетизации нет). Сделано в E07-05 ([ADR-0053](../adr/0053-post-actions-menu.md)): кнопка
  «Меню поста» в конце шапки; автору «Редактировать» и «Удалить» (с подтверждением «Удалить пост?»), читателю и гостю
  «Пожаловаться», «Скрыть», «Скопировать ссылку». Пункты без готового функционала («Редактировать», «Пожаловаться»,
  «Скрыть») скрыты флагами; остальные пункты добавляют свои задачи.

## Телефон, 390 px

```text
┌──────────── 390 ────────────┐
│ [←]  знак            [ … ]  │
├─────────────────────────────┤
│ аватар Автор · Тема · дата  │
│ Заголовок                   │
│ блоки во всю ширину,        │
│ поля --space-4              │
│ …                           │
│ Комментарии                 │
├─────────────────────────────┤
│ ♥ 12 · 💬 4 · закладка · ⇪ │  панель действий над нижней панелью
├─────────────────────────────┤
│ Лента Рейтинг Увед. Сообщ. Меню │
└─────────────────────────────┘
```

- Медиаблоки во всю ширину без полей; галерея листается свайпом, масштаб щипком (FR-MEDIA).
- Панель действий прилипает над нижней панелью; «Поделиться» открывает системное меню телефона.
- На телефоне у кнопок панели только значки: подписи остаются для чтения с экрана, видимые не помещались в 390 px
  (E09-02).
- Меню «…» и список оценивших — нижние шторки; реакция — долгим нажатием на «♥».
- Плавающая «Написать» на странице поста скрыта, чтобы не перекрывать панель действий (предложение, требует
  подтверждения; так сделано в E07-04, ADR-0050).

## Состояния

### Пусто

- У поста нет реакций, репостов и ответов: счётчики не показываются, список «Репосты и ответы» скрыт.
- Нет комментариев: состояние «Пусто» из [comments.md](comments.md).
- Нет рекомендаций: блок рекомендаций не выводится.

### Загрузка

- Открытие из ленты: шапка карточки и заголовок показываются сразу из данных ленты, тело — скелетоном строк.
- Прямой заход по адресу: скелетон шапки, заголовка и трёх абзацев; медиаблоки — размытое превью и доминирующий
  цвет до загрузки (FR-MEDIA).
- Комментарии и рекомендации грузятся после тела поста, каждый со своим скелетоном.

### Ошибка

- Пост не найден или удалён — страница 404 (FR-UI); снят с публикации или скрыт — «доступ закрыт» с причиной,
  если её можно показывать.
- Сбой загрузки — блок ошибки с «Повторить» в центральной колонке.
- Ошибка действия — тост, кнопка возвращается в прежнее состояние.

## Поведение и доступность

- Пост — `article` с заголовком `h1`; панель действий — `toolbar` с подписями кнопок и числами счётчиков.
- `Esc` или «← назад» на десктопе возвращают в ленту; горячая клавиша `l` — реакция «лайк» (предложение, требует
  подтверждения).
- Учёт просмотра и времени чтения (FR-POST) не влияет на интерфейс.
