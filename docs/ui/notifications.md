# Экран «Уведомления»

Требования: FR-NOTIFY (события, лента уведомлений, группировка, каналы), мост с Telegram (предложение переноса
поста, [telegram-bridge.md](../telegram-bridge.md)), FR-UI; раскладка —
[раздел 5 ТЗ](../spec.md#5-десктопная-и-мобильная-версии).

Две формы: выпадающая панель «колокольчика» в шапке десктопа и полная страница `/notifications` (на телефоне —
вкладка «Уведомления» нижней панели).

## Десктоп, 1440 px

```text
                                     шапка: … [Написать] [🔔 3] [аватар]
                                                 ┌ панель (--size-aside) ───────────┐
                                                 │ Уведомления  [Прочитать все] [⚙] │
                                                 │ ● (ав) Имя ответил на комментарий │
                                                 │   «…» · 5 мин                     │
                                                 │ ● (ав)(ав) Имя и ещё 4 оценили    │
                                                 │   пост «…» · 1 ч                  │
                                                 │   (ав) Новый подписчик · вчера    │
                                                 │ ─────────────────────────────────│
                                                 │ Все уведомления →                 │
                                                 └───────────────────────────────────┘
```

- Значок колокольчика `--size-icon-md` со счётчиком непрочитанных (`--color-accent`, `--color-on-accent`,
  `--radius-full`, `--font-size-xs`); больше 99 — «99+».
- Панель шириной `--size-aside` (предложение, требует подтверждения), высота до 70 % окна с прокруткой, фон
  `--color-surface`, тень и `--radius-md`; закрывается по `Esc` и клику вне её.
- Строка: аватар `--size-mark`, текст события `--font-size-sm`, время `--color-muted`; непрочитанное — точка и фон
  `--color-surface-subtle`. Однотипные события сгруппированы («Имя и ещё 4»).
- Меню строки: «Отписаться от треда»; «⚙» ведёт в настройки уведомлений ([settings.md](settings.md)).
- Полная страница `/notifications` — та же лента в центральной колонке `--size-feed` с фильтром по типам событий
  (предложение, требует подтверждения).
- Предложение переноса поста из Telegram — строка с кнопками «Перенести» и «Не сейчас».

## Телефон, 390 px

```text
┌──────────── 390 ────────────┐
│ Уведомления   [✓ все] [⚙]   │
├─────────────────────────────┤
│ ● (ав) Имя ответил…   5 мин │
│ ● (ав)(ав) Имя и ещё 4…  1 ч│
│   (ав) Новый подписчик      │
│ …                           │
├─────────────────────────────┤
│ Лента Рейтинг ▸Увед.³ Сообщ. Меню │
└─────────────────────────────┘
```

- Полноэкранный список, строки во всю ширину, высота строки не меньше 44 px; обновление «потянуть вниз».
- Счётчик непрочитанного — на иконке вкладки «Уведомления»; открытие вкладки не помечает всё прочитанным, отметка
  ставится по показу строки (предложение, требует подтверждения).
- Меню строки — нижняя шторка; push-уведомления — после согласия в PWA (раздел 5 ТЗ).

## Состояния

### Пусто

- «Уведомлений пока нет» и подсказка, что сюда приходят ответы, реакции и подписчики; в панели — то же одной строкой.

### Загрузка

- Скелетон пяти строк (круг и две строки) в панели и на странице; подгрузка — одна строка скелетона внизу.

### Ошибка

- Сбой загрузки — «Не удалось загрузить уведомления» и «Повторить» внутри панели или страницы.
- «Прочитать все» не удалось — тост, точки непрочитанного возвращаются.
- Потеря связи реального времени — счётчик обновляется после переподключения, без сообщения пользователю.

## Поведение и доступность

- Счётчик — часть подписи кнопки («Уведомления, 3 непрочитанных»); новые события объявляются через `aria-live`
  вежливо.
- Клик по строке открывает объект события (пост, комментарий, блог) и помечает строку прочитанной.
