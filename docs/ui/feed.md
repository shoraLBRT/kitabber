# Экран «Лента»

Требования: FR-FEED (ленты, карточка поста, пагинация, виджеты), FR-POST (меню действий), FR-REACT (реакции и
счётчики), FR-SUB (скрытие поста и темы), FR-UI; раскладка — [раздел 5 ТЗ](../spec.md#5-десктопная-и-мобильная-версии).
Общий каркас и общие состояния — [README.md](README.md).

Адреса: `/` (главная лента по настройке, по умолчанию «Популярное»), `/popular`, `/new` (уже работает, ADR-0043), `/my`, `/top/<период>` (работает: `day`, `week`, `month`, `year`, `all`, ADR-0104),
`/viewed` — предложение, требует подтверждения (адреса лент в ТЗ не заданы).

## Десктоп, 1440 px

```text
┌ левое меню ┐┌──────────────── лента (--size-feed) ────────────────┐┌ правая колонка ┐
│ ▸Популярное││ [Новости редакции — виджет над лентой]              ││ Популярные     │
│  Свежее    ││ ┌ панель ленты ─────────────────────────────────┐   ││ комментарии    │
│  Моя лента ││ │ Популярное | Свежее | Моя лента   [фильтр ▾]  │   ││                │
│  …         ││ └───────────────────────────────────────────────┘   ││ Интересные     │
│            ││        [ Показать новые ] (плашка, прилипает)       ││ блоги          │
│            ││ ┌ карточка поста ───────────────────────────────┐   ││                │
│            ││ │ аватар Автор · Тема · дата            [ … ]   │   ││ (прилипает     │
│            ││ │ Заголовок                                     │   ││  при прокрутке)│
│            ││ │ превью блоков / обложка                       │   ││                │
│            ││ │ Показать полностью                            │   ││                │
│            ││ │ ♥ реакции · комментарии · просмотры · закладка│   ││                │
│            ││ │ лучший комментарий                            │   ││                │
│            ││ └───────────────────────────────────────────────┘   ││                │
│            ││ … бесконечная подгрузка …                           ││                │
└────────────┘└─────────────────────────────────────────────────────┘└────────────────┘
```

- Активная лента подсвечена в левом меню (`--color-accent`), та же лента выбрана в панели ленты.
- Над лентой — быстрый пост: поле текста, фото, тема, «Развернуть» и «Опубликовать»; гостю — приглашение войти. На
  телефоне его открывает плавающая «Написать» ([editor.md](editor.md#быстрый-пост),
  [ADR-0055](../adr/0055-quick-post.md)).
- Панель ленты: для «Свежее» — фильтр рейтинга (все, от −10, от +5, от +10); для «Моя лента» — сортировка по
  популярности или дате; для «Топ» — период (день, неделя, месяц, год, всё время). Переключатель периода сделан (E08-06,
  [ADR-0104](../adr/0104-top-periods.md)): ряд ссылок «За день … За всё время» под заголовком «Популярное», текущий период
  отмечен `aria-current`, на телефоне ряд прокручивается вбок; пустой период — заглушка со ссылкой на «Свежее».
  Фильтр «Свежего» сделан (E08-07, [ADR-0106](../adr/0106-fresh-rating-filter.md)): ряд кнопок «Все», «От −10»,
  «От +5», «От +10» под заголовком «Свежее», выбранная отмечена `aria-pressed`, на телефоне ряд прокручивается вбок;
  порог применяет сервер, выбор хранится в настройках аккаунта (у гостя — в браузере); пустая лента при пороге — «С
  таким рейтингом постов пока нет…» и «Показать все».
- Карточка: фон `--color-surface`, скругление `--radius-lg`, внутренние поля `--space-5`, промежуток между
  карточками `--space-4`. Заголовок `--font-size-xl` `--font-weight-bold`, текст превью `--font-size-md`, мета
  (тема, дата) `--font-size-sm` `--color-muted`. Аватар автора `--size-mark`.
- Короткий пост показывается целиком; лонгрид обрезается с «Показать полностью», которое раскрывает пост на месте.
  Порог обрезки ([ADR-0052](../adr/0052-feed-post-card.md), предложено, требует подтверждения): не больше 3 блоков
  и ни одного блока после того, на котором текст превью достиг 600 знаков; первый блок показывается всегда.
- Мета карточки: аватар и имя автора (ссылка на его блог), тема (ссылка, только для поста в теме), дата — ссылка на
  пост; заголовок — тоже ссылка на пост. У короткого поста без заголовка заголовка нет: пост открывается по дате.
- Лучший комментарий ([ADR-0062](../adr/0062-feed-best-comment.md)): у поста с комментариями под строкой счётчиков
  (пока её нет — последним блоком карточки) — самый лайкнутый показанный комментарий, при равенстве более ранний.
  Блок на фоне `--color-surface-subtle` со скруглением `--radius-md`: аватар `sm`, имя автора (блог или имя гостя)
  `--font-size-sm` `--font-weight-medium` и до трёх строк текста с многоточием. Весь блок — ссылка на комментарий на
  странице поста (`#comment-<id>`); комментарий глубже прочитанного открывается экраном своей ветки. Без комментариев
  блока нет. Одинаково на десктопе и телефоне.
- Меню «…»: скрыть из ленты, скрыть тему, заблокировать автора, пожаловаться, скопировать ссылку, написать
  пост-ответ; на своём посте — действия автора (FR-POST).
- Клик по карточке открывает пост на той же странице, позиция ленты сохраняется ([post.md](post.md)).

## Телефон, 390 px

```text
┌──────────── 390 ────────────┐
│ знак                [поиск] │  шапка прячется при прокрутке вниз
│ Популярное Свежее Моя лента │  вкладки лент под шапкой
├─────────────────────────────┤
│ [ Показать новые ]          │
│ аватар Автор · Тема    [ … ]│  карточка во всю ширину,
│ Заголовок                   │  без скруглений
│ превью                      │
│ ♥ · комм. · просм. · закл.  │
├─────────────────────────────┤
│ …                    [ + ]  │
├─────────────────────────────┤
│ ▸Лента Рейтинг Увед. Сообщ. Меню │
└─────────────────────────────┘
```

- Вкладки лент — горизонтальная полоса под шапкой, прокручивается вбок, если не помещается; фильтр — кнопка справа
  на полосе, открывает нижнюю шторку.
- Карточки во всю ширину, без скруглений, разделены промежутком `--space-2` цвета `--color-background`; поля
  внутри `--space-4`.
- Меню «…» и выбор реакции — нижние шторки; реакция по долгому нажатию на «♥».
- Обновление жестом «потянуть вниз»; виджеты правой колонки на телефоне не показываются (предложение, требует
  подтверждения).

## Состояния

### Пусто

- «Моя лента» пуста (подписок нет или у подписок нет постов — API их не различает): текст «Здесь появятся посты блогов
  и тем, на которые вы подпишетесь…», до шести тем ссылками на их страницы и «Найти авторов в «Свежем»» (ADR-0089;
  «Рейтинга», куда вела кнопка «Найти блоги и темы», ещё нет). Гостю — «Войдите…» с кнопкой окна входа.
- Подписки есть, постов нет, или фильтр рейтинга всё отсёк: «Здесь пока нет постов» и предложение сменить фильтр.
- «Просмотренные» пусто: «Вы ещё ничего не открывали».

### Загрузка

- Первая загрузка: три скелетона карточек (аватар, две строки, прямоугольник превью) цвета `--color-surface-subtle`.
- Подгрузка следующей страницы: один скелетон карточки внизу; запрос начинается за экран до конца ленты.
- «Показать новые» не сдвигает ленту: новые посты вставляются сверху только по нажатию. Сделано для «Свежего» (E08-08,
  [ADR-0108](../adr/0108-show-new-posts.md)): раз в минуту, пока вкладка видна, и при возвращении во вкладку страница
  перечитывает первую страницу ленты с тем же порогом рейтинга; плашка «Показать новые» с числом новых («N+», если
  новая вся первая страница) прилипает под шапкой поверх карточек — у неё нет своего места в ленте. Нажатие ставит
  новые посты сверху и прокручивает к началу. Пока новых нет и при сбое проверки плашки нет.
- На телефоне (E08-14, [ADR-0111](../adr/0111-pull-to-refresh-and-hiding-header.md)) ленту обновляет жест «потянуть
  вниз» от самого начала страницы: над лентой раскрывается отметка со стрелкой — «Потяните, чтобы обновить», дальше
  64 px — «Отпустите, чтобы обновить», после — крутится «Обновляем ленту…». На «Свежем» новые посты встают сверху, как
  по «Показать новые»; остальные ленты читаются заново. Шапка прячется при прокрутке вниз и возвращается при прокрутке
  вверх; плашка «Показать новые» поднимается вслед за ней. На десктопе шапка не двигается.

### Ошибка

- Первая страница не загрузилась: блок ошибки на месте ленты с кнопкой «Повторить».
- Следующая страница не загрузилась: строка «Не удалось загрузить» с «Повторить» внизу ленты, загруженное
  остаётся.
- Ошибка действия (реакция, закладка, скрытие) — тост, состояние кнопки откатывается.

### Нет интернета

Общая плашка из [README.md](README.md); уже загруженная лента остаётся доступной для чтения.

## Поведение и доступность

- Лента — список `feed` с карточками-`article`; клавиши на десктопе: `j`/`k` — следующая/предыдущая карточка,
  `Enter` — открыть (предложение, требует подтверждения; FR-UI требует горячих клавиш, набор не задан).
- Позиция и загруженные страницы восстанавливаются при возврате назад (FR-FEED).
- Настройки лент (главная по умолчанию, скрывать просмотренные, автопроигрывание видео, контент для взрослых) —
  в [settings.md](settings.md).
