# Экран «Лента»

Требования: FR-FEED (ленты, карточка поста, пагинация, виджеты), FR-POST (меню действий), FR-REACT (реакции и
счётчики), FR-SUB (скрытие поста и темы), FR-UI; раскладка — [раздел 5 ТЗ](../spec.md#5-десктопная-и-мобильная-версии).
Общий каркас и общие состояния — [README.md](README.md).

Адреса: `/` (главная лента по настройке, по умолчанию «Популярное»), `/popular`, `/new`, `/my`, `/top/<период>`,
`/viewed` — предложение, требует подтверждения (адреса лент в ТЗ не заданы).

## Десктоп, 1440 px

```text
┌ левое меню ┐┌──────────────── лента (--size-feed) ────────────────┐┌ правая колонка ┐
│ ▸Популярное││ [Новости редакции — виджет над лентой]              ││ Популярные     │
│  Свежее    ││ ┌ панель ленты ─────────────────────────────────┐   ││ комментарии    │
│  Моя лента ││ │ Популярное | Свежее | Моя лента   [фильтр ▾]  │   ││                │
│  …         ││ └───────────────────────────────────────────────┘   ││ Интересные     │
│            ││        [ Показать новые ] (плашка, прилипает)       ││ блоги          │
│            ││ ┌ карточка поста ───────────────────────────────┐   ││                │
│            ││ │ аватар Автор · Тема · дата            [ … ]   │   ││ (прилипает     │
│            ││ │ Заголовок                                     │   ││  при прокрутке)│
│            ││ │ превью блоков / обложка                       │   ││                │
│            ││ │ Показать полностью                            │   ││                │
│            ││ │ ♥ реакции · комментарии · просмотры · закладка│   ││                │
│            ││ │ лучший комментарий                            │   ││                │
│            ││ └───────────────────────────────────────────────┘   ││                │
│            ││ … бесконечная подгрузка …                           ││                │
└────────────┘└─────────────────────────────────────────────────────┘└────────────────┘
```

- Активная лента подсвечена в левом меню (`--color-accent`), та же лента выбрана в панели ленты.
- Панель ленты: для «Свежее» — фильтр рейтинга (все, от −10, от +5, от +10); для «Моя лента» — сортировка по
  популярности или дате; для «Топ» — период (день, неделя, месяц, год, всё время).
- Карточка: фон `--color-surface`, скругление `--radius-lg`, внутренние поля `--space-5`, промежуток между
  карточками `--space-4`. Заголовок `--font-size-xl` `--font-weight-bold`, текст превью `--font-size-md`, мета
  (тема, дата) `--font-size-sm` `--color-muted`. Аватар автора `--size-mark`.
- Короткий пост показывается целиком; лонгрид обрезается по высоте с «Показать полностью» (порог обрезки —
  предложение, требует подтверждения: 3 блока или высота экрана).
- Меню «…»: скрыть из ленты, скрыть тему, заблокировать автора, пожаловаться, скопировать ссылку, написать
  пост-ответ; на своём посте — действия автора (FR-POST).
- Клик по карточке открывает пост на той же странице, позиция ленты сохраняется ([post.md](post.md)).

## Телефон, 390 px

```text
┌──────────── 390 ────────────┐
│ знак                [поиск] │  шапка прячется при прокрутке вниз
│ Популярное Свежее Моя лента │  вкладки лент под шапкой
├─────────────────────────────┤
│ [ Показать новые ]          │
│ аватар Автор · Тема    [ … ]│  карточка во всю ширину,
│ Заголовок                   │  без скруглений
│ превью                      │
│ ♥ · комм. · просм. · закл.  │
├─────────────────────────────┤
│ …                    [ + ]  │
├─────────────────────────────┤
│ ▸Лента Рейтинг Увед. Сообщ. Меню │
└─────────────────────────────┘
```

- Вкладки лент — горизонтальная полоса под шапкой, прокручивается вбок, если не помещается; фильтр — кнопка справа
  на полосе, открывает нижнюю шторку.
- Карточки во всю ширину, без скруглений, разделены промежутком `--space-2` цвета `--color-background`; поля
  внутри `--space-4`.
- Меню «…» и выбор реакции — нижние шторки; реакция по долгому нажатию на «♥».
- Обновление жестом «потянуть вниз»; виджеты правой колонки на телефоне не показываются (предложение, требует
  подтверждения).

## Состояния

### Пусто

- «Моя лента» без подписок: текст «Вы пока ни на кого не подписаны» и кнопка «Найти блоги и темы» (ведёт в
  «Рейтинг»).
- Подписки есть, постов нет, или фильтр рейтинга всё отсёк: «Здесь пока нет постов» и предложение сменить фильтр.
- «Просмотренные» пусто: «Вы ещё ничего не открывали».

### Загрузка

- Первая загрузка: три скелетона карточек (аватар, две строки, прямоугольник превью) цвета `--color-surface-subtle`.
- Подгрузка следующей страницы: один скелетон карточки внизу; запрос начинается за экран до конца ленты.
- «Показать новые» не сдвигает ленту: новые посты вставляются сверху только по нажатию.

### Ошибка

- Первая страница не загрузилась: блок ошибки на месте ленты с кнопкой «Повторить».
- Следующая страница не загрузилась: строка «Не удалось загрузить» с «Повторить» внизу ленты, загруженное
  остаётся.
- Ошибка действия (реакция, закладка, скрытие) — тост, состояние кнопки откатывается.

### Нет интернета

Общая плашка из [README.md](README.md); уже загруженная лента остаётся доступной для чтения.

## Поведение и доступность

- Лента — список `feed` с карточками-`article`; клавиши на десктопе: `j`/`k` — следующая/предыдущая карточка,
  `Enter` — открыть (предложение, требует подтверждения; FR-UI требует горячих клавиш, набор не задан).
- Позиция и загруженные страницы восстанавливаются при возврате назад (FR-FEED).
- Настройки лент (главная по умолчанию, скрывать просмотренные, автопроигрывание видео, контент для взрослых) —
  в [settings.md](settings.md).
