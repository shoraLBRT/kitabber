# Экран «Настройки»

Требования: FR-AUTH (почта, пароль, провайдеры входа, устройства, заморозка и удаление), FR-PROFILE (настройки
блога), FR-FEED (настройки лент), FR-NOTIFY (каналы и типы событий), FR-SUB (чёрный список, скрытые темы), FR-MSG
(запрет входящих), FR-UI (тема оформления, шрифт, язык); раскладка —
[раздел 5 ТЗ](../spec.md#5-десктопная-и-мобильная-версии).

Адрес: `/settings` — список разделов, раздел — `/settings/<раздел>` (E04-08, [ADR-0070](../adr/0070-settings-sections-and-account-preferences.md)).
Разделы по порядку: «Блог» (`blog`), «Ленты» (`feeds`), «Основные» (`general`), «Уведомления» (`notifications`),
«Приватность и блокировки» (`privacy`), «Аккаунт и вход» (`account`), «Настройки cookie» (`cookies`).
Список задаётся в одном месте — `settingsNav` в `frontend/utils/navigation.ts`.

## Десктоп, 1440 px

```text
┌ левое меню ┐┌──────────── настройки (--size-feed) ────────────────┐┌ правая колонка ┐
│            ││ Настройки                                           ││ Разделы:       │
│            ││ ─ Блог ─────────────────────────────────────────    ││ ▸ Блог         │
│            ││ Название           [________________] 0/25          ││   Аккаунт      │
│            ││ Описание           [________________] 0/160         ││   Ленты        │
│            ││ Никнейм @          [________] ✓ свободен            ││   Уведомления  │
│            ││ Кто может комментировать   [Все ▾]                  ││   Приватность  │
│            ││ [✓] Показывать посты всем                           ││   Основные     │
│            ││ [✓] Показывать, когда я онлайн                      ││                │
│            ││                                   [Сохранить]       ││                │
└────────────┘└─────────────────────────────────────────────────────┘└────────────────┘
```

- Навигация по разделам — в правой колонке на месте виджетов (заголовок «Настройки», открытый раздел выделен),
  раздел — в центральной (E04-08). Где правой колонки нет (уже 1240 px), заголовок раздела начинается с «←» к списку
  `/settings`.
- Поля: подпись `--font-size-sm` `--font-weight-medium`, поле с границей `--color-border-strong` и `--radius-md`,
  счётчик символов `--color-muted`; между полями `--space-5`, между группами `--space-8`.
- **Блог** (`/settings/blog`, сделано в E04-03: аватар, название и описание; «Ред.» и «Настройки» своего блога
  ведут сюда): аватар — «Загрузить аватар» открывает окно кадрирования (картинка под круглой рамкой, перетаскивание
  и стрелки, ползунок «Масштаб», «Применить» и «Отмена»; [ADR-0034](../adr/0034-profile-editing-and-avatar.md)),
  «Убрать аватар»; название (до 25), описание (до 160), никнейм (проверка занятости, смена не чаще раза в 30 дней — дата
  следующей смены под полем), кто может комментировать, «показывать посты всем», «показывать, когда я онлайн».
- **Аккаунт и вход** (`/settings/account`; пароль сделан в E03-05, [ADR-0036](../adr/0036-password-reset-and-change.md):
  текущий и новый пароль, «Сменить пароль», письмо о смене; без пароля — сброс через «Забыли пароль?» во входе):
  почта и пароль (смена с подтверждением кодом), провайдеры входа (привязать и отвязать),
  устройства с «Выйти со всех устройств» (сделано в E03-09, [ADR-0078](../adr/0078-device-sessions-and-sign-out-everywhere.md):
  браузер и система, «Последняя активность», метка «Это устройство», «Выйти» у остальных, общий выход — после
  подтверждения в окне), заморозка и удаление аккаунта (кнопки `--color-danger` с подтверждением в
  окне).
- **Ленты** (`/settings/feeds`; пока место раздела и фраза о том, что в нём будет, E04-08; содержание — E08-13 и
  E08-10): главная лента по умолчанию, скрывать просмотренные, автопроигрывание видео, контент для взрослых.
- **Уведомления** (`/settings/notifications`; пока место раздела и фраза о том, что в нём будет, E04-08; таблица —
  E12-05): таблица «тип события × канал» (сайт, push, почта) с галочками.
- **Приватность и блокировки** (`/settings/privacy`; чёрный список сделан в E11-06,
  [ADR-0091](../adr/0091-black-list.md)): «Чёрный список» — подсказка, что делает блокировка, строки с именем блога
  (ссылка на блог) и датой «В списке с …», «Разблокировать» и сообщение «… больше не в чёрном списке.»; пусто —
  «В чёрном списке никого нет.»; загрузка — скелетон, сбой — «Повторить». Потом — скрытые темы (E11-07), запрет
  входящих сообщений (FR-MSG).
- **Основные** (`/settings/general`, сделано в E04-08, [ADR-0070](../adr/0070-settings-sections-and-account-preferences.md)):
  тема оформления — радиокнопки «Как в системе», «Светлая», «Тёмная» с подсказкой «Выбор сохраняется в аккаунте и
  действует на всех ваших устройствах». Выбор применяется сразу и сохраняется в аккаунт, тост «Изменения сохранены»;
  переключатель темы левого меню сохраняет туда же. Потом — шрифт и сглаживание, язык интерфейса.
- **Настройки cookie** (`/settings/cookies`, сделано в E02-13,
  [ADR-0066](../adr/0066-cookie-consent.md)): открыты гостям — выбор принадлежит браузеру. «Необходимые» —
  отмеченная недоступная галочка, «Аналитические» — галочка, «Сохранить выбор» и тост «Выбор сохранён». Сюда ведут
  «Настроить» баннера согласия и служебная ссылка «Настройки cookie» левого меню и экрана «Меню». Баннер — внизу
  каждой страницы до выбора: «Только необходимые» и «Разрешить все» одного вида, «Настроить»; на десктопе над правой
  колонкой, на телефоне во всю ширину над нижней панелью.
- Переключатели применяются сразу; поля с текстом — кнопкой «Сохранить» в конце раздела (предложение, требует
  подтверждения).

## Телефон, 390 px

```text
┌──────────── 390 ────────────┐         ┌──────────── 390 ────────────┐
│ [←] Настройки               │   →     │ [←] Блог                    │
├─────────────────────────────┤         ├─────────────────────────────┤
│ Блог                      > │         │ Название                    │
│ Аккаунт и вход            > │         │ [_______________________]   │
│ Ленты                     > │         │ Описание                    │
│ Уведомления               > │         │ [_______________________]   │
│ Приватность и блокировки  > │         │ …                           │
│ Основные                  > │         │ [       Сохранить       ]   │
└─────────────────────────────┘         └─────────────────────────────┘
```

- Вход — из экрана «Меню» (раздел 5 ТЗ). Первый экран — список разделов (строки не ниже 44 px), раздел открывается
  отдельным экраном с «←».
- Подписи над полями, поля во всю ширину минус `--space-4` с каждой стороны; «Сохранить» — во всю ширину внизу
  раздела.
- Таблица уведомлений на телефоне — список типов событий, у каждого три переключателя каналов в строку.
- Выпадающие списки — нижние шторки.

## Состояния

### Пусто

- Чёрный список пуст: «Вы никого не блокировали». Скрытых тем нет: «Скрытых тем нет».
- Нет привязанных провайдеров: список провайдеров с кнопками «Привязать». Одно устройство: список из текущего с
  пометкой «Это устройство».

### Загрузка

- Скелетон полей раздела (подпись и поле) при первом открытии; сохранение — кнопка «Сохранить» с индикатором и
  неактивна, поля доступны.
- Проверка никнейма — «Проверяем…» под полем.

### Ошибка

- Ошибки полей (длина, занятый никнейм, лимит смены никнейма, неверный код) — подпись под полем `--color-danger`,
  фокус на первом поле с ошибкой.
- Раздел не загрузился — блок ошибки с «Повторить» на месте раздела.
- Сохранение не удалось — тост, введённые значения остаются; переключатель возвращается в прежнее положение.
- Не вошедший пользователь — переход на вход и возврат в настройки после входа.

## Поведение и доступность

- У каждого поля связанная подпись и описание ошибки (`aria-describedby`); переключатели — `switch`.
- Уход со страницы с несохранёнными изменениями спрашивает подтверждение.
- Опасные действия (удаление аккаунта, выход со всех устройств) требуют подтверждения в окне и не выполняются по
  одному нажатию.
