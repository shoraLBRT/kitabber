# Спецификации ключевых экранов

Задача E02-03 (#13). Вместо макетов в графическом редакторе — текстовые спецификации: схема раскладки, размеры и
состояния каждого ключевого экрана на двух опорных ширинах, **1440 px** (десктоп) и **390 px** (телефон).
Источник требований — [ТЗ, раздел 5 «Десктопная и мобильная версии»](../spec.md#5-десктопная-и-мобильная-версии) и
[FR-UI «Общий интерфейс»](../spec.md#fr-ui-общий-интерфейс); у каждого экрана указаны свои разделы FR.

Размеры и цвета задаются **именами токенов** из [ADR-0012](../adr/0012-design-tokens.md) (`brand/tokens.json`,
палитра `brand/brand.json`, CSS-переменные в `brand/tokens.css`), а не сырыми значениями. Где токена нет, значение
записано в пикселях и помечено. Бренд, графику и тексты DTF не копируем — только механику и раскладку. Монетизации
нет: пунктов «донаты», «подписка» (платная), продвижения и подарков на экранах нет, даже где они упомянуты в ТЗ как
устройство DTF.

Каждый файл устроен одинаково: назначение и адреса, раздел «1440 px», раздел «390 px», раздел «Состояния» с
подразделами «Пусто», «Загрузка», «Ошибка» (и другими, если есть), поведение и доступность, предложения. Решения,
которых нет в ТЗ, помечены **«предложение, требует подтверждения»**.

## Раскладки и каркас

Четыре раскладки из раздела 5 ТЗ; границы — токены `breakpoint.sm` (640), `breakpoint.md` (925), `breakpoint.lg`
(1240).

| Ширина | Раскладка | Опорная ширина спецификаций |
| --- | --- | --- |
| от `breakpoint.lg` | Шапка; левое меню `--size-menu`, лента `--size-feed`, правая колонка `--size-aside` | **1440 px** |
| от `breakpoint.md` до `breakpoint.lg` | Как 1440 px, правая колонка скрыта | — |
| от `breakpoint.sm` до `breakpoint.md` | Одна колонка с полями, нижняя панель вкладок, левое меню скрыто | — |
| до `breakpoint.sm` | Одна колонка во всю ширину, карточки без скруглений, нижняя панель из 5 вкладок, плавающая «Написать» | **390 px** |

### Десктоп, 1440 px

```text
┌──────────────────────────────────────────── 1440 ────────────────────────────────────────────┐
│ Шапка: знак · [поиск] ··························· [Написать] [колокольчик] [аватар]          │
├──────────────┬────────────────────────────────────────────┬──────────────────────────────────┤
│ Левое меню   │ Центральная колонка                        │ Правая колонка (прилипает)       │
│ --size-menu  │ --size-feed                                │ --size-aside                     │
│ Популярное   │ содержимое экрана                          │ «Популярные комментарии»         │
│ Свежее       │                                            │ «Интересные блоги»               │
│ Моя лента    │                                            │                                  │
│ Сообщения    │                                            │                                  │
│ Рейтинг      │                                            │                                  │
│ Темы…        │                                            │                                  │
│ О проекте    │                                            │                                  │
│ Правила      │                                            │                                  │
│ Тема оформл. │                                            │                                  │
└──────────────┴────────────────────────────────────────────┴──────────────────────────────────┘
```

- Три колонки занимают `--size-menu` + `--size-feed` + `--size-aside` и промежутки `--space-6` между ними; блок
  центрируется, поля по краям — остаток ширины. Промежуток `--space-6` — предложение, требует подтверждения.
- Шапка во всю ширину, высота `--space-16` (предложение, требует подтверждения), фон `--color-surface`, нижняя
  граница `--size-border` цвета `--color-border`. Поиск по нажатию раскрывается на ширину ленты и затемняет
  страницу (FR-SEARCH).
- Меню аватара: профиль, черновики, закладки, тема оформления, настройки, выход. Пункт «коллекция» из ТЗ не
  показывается, пока у него нет описания в FR, «донаты» — никогда (предложение, требует подтверждения).
- Фон страницы `--color-background`, карточки `--color-surface` со скруглением `--radius-lg`, вторичный текст
  `--color-muted`, основная кнопка `--color-accent` с текстом `--color-on-accent`, фокус — обводка
  `--size-focus-ring` цвета `--color-focus`.

### Телефон, 390 px

```text
┌──────────── 390 ────────────┐
│ Шапка: знак · [поиск]       │  прячется при прокрутке вниз
├─────────────────────────────┤
│ Содержимое во всю ширину    │
│ карточки без скруглений     │
│                             │
│                    [ + ]    │  плавающая «Написать»
├─────────────────────────────┤
│ Лента Рейтинг Увед. Сообщ. Меню │  нижняя панель, счётчики на иконках
└─────────────────────────────┘
```

- Нижняя панель: «Лента», «Рейтинг», «Уведомления», «Сообщения», «Меню»; иконки `--size-icon-md`, нажимаемая
  область не меньше `--size-touch` (44 px, раздел 5 ТЗ), высота вкладки `--size-tab-bar`, учитываются безопасные
  зоны и «чёлка».
- Экран «Меню» заменяет левую колонку: профиль или вход, черновики, закладки, настройки, тема оформления,
  служебные ссылки. Пункты «коллекция» и «подписка» не показываются (как на десктопе).
- Плавающая кнопка «Написать» — круг `--radius-full`, `--color-accent`, над нижней панелью с отступом `--space-4`.
- Меню действий и выбор реакции — нижние шторки; выбор реакции — долгим нажатием.
- Поля по краям экрана `--space-4`.

### Как это сделано

Каркас десктопа (E02-05) — `frontend/components/shell/`. Пункты и адреса левого меню — один список
`frontend/utils/navigation.ts`: адреса «Популярное» `/popular` (и `/`), «Свежее» `/new`, «Моя лента» `/my`,
«Сообщения» `/messages`, «Рейтинг» `/rating`, все темы `/topics`, «О проекте» `/about`, «Правила» `/rules` —
предложение, требует подтверждения. Переключатель темы оформления в левом меню помнит выбор в этом браузере;
сохранение в аккаунт — на экране настроек ([settings.md](settings.md)). Уже 640 px в шапке остаются знак и поиск:
«Написать», колокольчик, аватар и «Войти» переезжают в плавающую кнопку, нижнюю панель и экран «Меню».

Поиск в шапке (E14-02, [ADR-0097](../adr/0097-search-suggestions-and-history.md)) — `ShellSearch`: на десктопе поле
раскрывается на ширину ленты над затемнённой страницей, уже 640 px — отдельным экраном с «Отмена». Пустое поле
показывает историю запросов этого браузера и аккаунта с «Очистить», ввод — подсказки «Блоги и темы» и «Посты» после
паузы 300 мс; стрелки выбирают строку, Enter открывает, Esc закрывает. Размеры списков и пауза — предложение,
требует подтверждения.

Результаты поиска (E14-03, [ADR-0124](../adr/0124-search-results-page.md)) — `/rating?q=`, куда ведёт Enter без
выбранной подсказки: поле запроса с «Отмена», ниже карточки блоков «Блоги», «Темы» (строки списков подписок с
«Подписаться») и «Посты» с кнопкой «Фильтры» («Только заголовки», период, порядок); у каждого блока «Показать ещё».
Пустой блок не показывается, пустой результат — заглушка «По запросу «…» ничего не нашлось»; загрузка — скелетоны,
сбой — ошибка с «Повторить». На телефоне блоки идут друг под другом на всю ширину. Размеры страниц — предложение,
требует подтверждения.

Каркас телефона (E02-06) — `ShellTabBar`, `ShellWriteButton` и `ShellMenuScreen` там же. По разделу 5 ТЗ нижняя
панель видна на всём, что уже `breakpoint.md` (925 px), а плавающая «Написать» — только уже `breakpoint.sm`
(640 px): между 640 и 924 px «Написать», колокольчик и аватар остаются в шапке. Повторное нажатие на текущую вкладку
прокручивает страницу наверх. Предложение, требует подтверждения: экран «Меню» — отдельная страница `/menu` (на
широком экране она повторяет левое меню); кроме пунктов ТЗ на нём есть темы с «Показать все» (они тоже в левой
колонке: темы, на которые человек подписан, или популярные для гостя; «Показать все» ведёт в каталог `/topics`,
[ADR-0088](../adr/0088-topic-menu-and-catalog.md)) и «Выйти» для вошедшего; адреса `/profile`, `/drafts`, `/bookmarks`,
`/settings`; счётчики больше 99
показываются как «99+»; тосты ниже 925 px поднимаются над панелью.

## Общие состояния (FR-UI)

Действуют на всех экранах; в файлах экранов описано только то, что отличается.

- **Загрузка** — скелетоны (блоки `--color-surface-subtle` в форме будущего содержимого), не крутилки. Каркас
  (шапка, меню, нижняя панель) показывается сразу.
- **Ошибка** — сообщение в области содержимого с кнопкой «Повторить», текст `--color-text`, значок `--color-danger`;
  каркас остаётся рабочим. Ошибка действия (не загрузки) — тост.
- **Нет интернета** — плашка над содержимым «Нет подключения», при возвращении сети — повторная загрузка.
- **404** и **«доступ закрыт»** — отдельные страницы в центральной колонке с ссылкой на главную.
- Сделано в E02-07 ([ADR-0057](../adr/0057-shared-states-and-error-pages.md)): `UiSkeleton` и `UiState` — общие
  скелетоны и сообщения; `error.vue` — 404 и 500 в каркасе; страница, чьё содержимое не найдено или не загрузилось,
  отдаёт при серверном рендеринге 404 или 500; плашка «Нет подключения» — `ShellOfflineBanner`, при возвращении сети
  перечитывается только то, что не загрузилось.
- **Тосты** — у нижнего края: на десктопе справа, на телефоне над нижней панелью.
- **Кнопка «наверх»** — при прокрутке дальше одного экрана; на телефоне — повторное нажатие на вкладку.
- **Баннер согласия на cookie** — у нижнего края при первом визите, по умолчанию отклоняет необязательные.
- **Тема оформления** — светлая, тёмная, системная; все токены цвета есть в обеих палитрах.
- **Клавиатура и дикторы** — порядок фокуса совпадает с визуальным, у иконок-кнопок есть подписи, горячие клавиши
  только на десктопе.

## Как это проверяется

Шаг verify «ui specs» (`scripts/ui-specs-test.ps1`) проверяет, что все восемь файлов на месте и в каждом есть
разделы 1440 px и 390 px, состояния «Пусто», «Загрузка», «Ошибка», ссылки на существующие разделы FR в
[spec.md](../spec.md), что упомянутые токены существуют, а относительные ссылки и якоря в `docs/` ведут на
существующие файлы и заголовки.
