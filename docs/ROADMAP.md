# Порядок работ

Задачи живут в GitHub Issues; здесь — их порядок. **Следующая задача — первая открытая сверху вниз, у которой
закрыты все зависимости** и нет меток `human`, `needs:decision`, `epic`. Вехи идут строго по порядку.

Обозначения: P0 — без задачи веха не закрывается, P1 — нужна для полноты, P2 — можно отложить. «Дни» — грубая
оценка в человеко-днях. Отметка «владелец» — задачу делает владелец; «ключи» — для боевой работы нужны ключи
или серверы от владельца, но задача выполняется на фейках.

Всего: 268 задач, 787 человеко-дней, 19 эпиков, 8 вех.
