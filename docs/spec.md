# kitabber: техническое задание

Этот документ — требования к платформе. Порядок работ — в [ROADMAP.md](ROADMAP.md), задачи — в GitHub Issues,
текущее состояние — в [PROJECT_STATE.md](PROJECT_STATE.md).

Связанные документы:

- [telegram-bridge.md](telegram-bridge.md) — мост с Telegram (FR-TG);
- [unified-accounts.md](unified-accounts.md) — подготовка к единому аккаунту (FR-ID);

## 1. Цели, рамки и решения владельца

kitabber (рабочее название) — этичная, преимущественно текстовая UGC-платформа: авторский контент, лонгриды,
научные статьи. По функциям и раскладке интерфейса платформа повторяет DTF (десктоп и мобильная версия), по
содержанию — отличается правилами: без пошлости, оскорблений и иного запрещённого контента.

**Решения владельца (19 ноября 2026).** Они перекрывают любой текст ниже, если тот им противоречит.

| Вопрос | Решение |
| --- | --- |
| Стек | ASP.NET Core (модульный монолит) и Nuxt 3, см. [ADR-0001](adr/0001-stack.md) |
| Тематика | Этичная текстовая платформа для всех. Ограничения контента в основном исламские, но продукт не позиционируется как исламский |
| Название | Временное — kitabber; финальное выберем позже. Название задаётся в одном месте кода |
| Кто создаёт темы | Пользователи: и темы (подсайты), и статьи |
| Монетизация | Не предусмотрена совсем: нет подписок, тарифов, донатов, подарков, рекламы и платежей |
| Мобильные приложения | В идеале отдельные приложения, но позже. Сейчас — качественная веб-версия и PWA |
| Модерация | Нужны модераторы с отдельным интерфейсом и автоматические фильтры |
| Telegram | Мост с каналами: импорт истории в один клик, ретрансляция новых постов, гостевые комментарии |
| Единый аккаунт | Сейчас не реализуем, но архитектура аккаунтов готовится к слиянию с другими проектами владельца |

**Что не копируем у DTF.** Название, логотип, фирменные цвета, иллюстрации, наборы реакций и стикеров, тексты
правил и чужой контент. Раскладку, навигацию и механику повторяем; бренд, графику и тексты делаем свои.

**Что не входит в проект.** Монетизация в любом виде. Партнёрские сервисы DTF (маркет, пополнение Steam, eSIM,
курсы, мини-игры, конвертер валют). Контент 18+ и связанные с ним метки и фильтры. Сторис.

**Что добавлено сверх паритета с DTF.** Мост с Telegram; блоки для научных статей (формулы, таблицы, сноски и
источники, оглавление); поддержка арабского текста и письма справа налево внутри контента; фильтры лексики и
изображений; обжалование решений модерации.

**Допущения.**

- Рынок запуска — Россия, язык интерфейса — русский, с заделом на локализацию.
- Раздел 2 описывает сам DTF таким, каким он был на 19 ноября 2026 (включая его монетизацию), и служит
  справкой; требования к kitabber начинаются с раздела 3.
- Экраны уведомлений, сообщений, закладок и черновиков на DTF были пусты в исследованном аккаунте и описаны
  по коду клиента.

## 2. Исследование DTF: карта функций

DTF состоит из 15 функциональных областей; ниже — что в каждой найдено на сайте (dtf.ru, просмотрены главная, пост, тема, блог, рейтинг, меню, клиентский код и API).

| Область | Что есть на DTF |
| --- | --- |
| Ленты | «Популярное», «Свежее», «Моя лента»; сортировка по популярности и дате; фильтр «Свежего» по рейтингу (все, от −10, от +5, от +10); топ за день, неделю, месяц, год, всё время; лента «Просмотренные»; плашка «Показать новые»; бесконечная подгрузка; виджет новостей редакции; скрытие просмотренного |
| Карточка поста в ленте | Автор с аватаром и бейджем, тема, дата, пометка «изменено», заголовок, первые блоки, «Показать полностью», ряд реакций, счётчики комментариев, закладок, репостов и просмотров, «Поделиться», подарок, лучший комментарий под карточкой, кнопка «Кратко», меню «…» |
| Страница поста | Полный текст, предупреждение от редакции, озвучка «Слушать», краткое содержание от ИИ, плавающая панель действий (лайк, комментарии, поделиться), репосты и «ответы на пост», статистика поста, история версий, рекомендации под постом, соавтор, блюр для 18+ |
| Редактор | Автору доступны 12 блоков: текст, подзаголовки H2 и H3, фото или видео, ссылка, цитата, список, код, разделитель, аудио, опрос, персона; меню блоков с поиском. Выделение в тексте: жирный, курсив, маркер, ссылка. В коде клиента есть ещё врезка, предупреждение, спойлер, число, кнопка, файл и игровой блок, но обычному автору они не предлагаются. Эмбеды по ссылке (YouTube, Twitch, Vimeo, Coub, VK, TikTok, Telegram, Instagram, Spotify, Яндекс Музыка, Steam). Шапка редактора: «назад», автор, выбор темы с поиском или «без темы», круглая кнопка публикации. На десктопе редактор открывается окном поверх ленты, на телефоне — на весь экран. Черновики с автосохранением, история версий, право комментирования, репост и пост-ответ, лимиты размера |
| Медиа | Загрузка файлов и извлечение по ссылке, изображения с ресайзом на лету и WebP, размытые превью, видео и GIF как видео с автопроигрыванием, поиск GIF и избранные GIF, подписи к медиа, полноэкранный просмотр |
| Комментарии | Дерево с ветками и сворачиванием, сортировка «Популярные» и «По дате», вложения (фото, видео, GIF), упоминания, реакции, закладки, редактирование и удаление, закрепление автором поста, счётчик новых с момента прошлого визита, жалобы, удаление ветки, донат в комментарии, виджет «Популярные комментарии» |
| Реакции и карма | Лайк и набор анимированных реакций на постах и комментариях, список оценивших, ограничения по карме («Слишком маленькая карма»), запрет оценивать себя |
| Блог (личная страница) | Обложка с перетаскиванием, аватар (и видеоаватар), имя, никнейм или id, описание, счётчики подписчиков и подписок, статус «онлайн», вкладки «Посты» и «Комментарии», сортировка постов, закреплённый пост, витрина ачивок и подарков, кнопки «Подписаться», «Написать», «Задонатить», «Подарить», статистика блога, скрытый профиль |
| Темы (сообщества) | Страница темы с обложкой, описанием и числом подписчиков, подписка, уведомления о новых постах, скрытие темы из лент, список тем в боковом меню, хэштеги (/tag/…) |
| Подписки и фильтрация | Подписка на блоги и темы, «Мои подписки», массовая отписка, чёрный список пользователей, скрытие поста из ленты, настройка контента для взрослых |
| Уведомления и сообщения | Лента уведомлений со счётчиком, «прочитать все», настройки по типам, браузерные push, письма. Мессенджер: список диалогов, поиск, вложения, редактирование и удаление сообщений, блокировка собеседника |
| Поиск и рейтинг | Быстрый поиск с историей запросов, полный поиск по постам, блогам и темам с фильтрами (точное совпадение, только заголовки, период, порядок). Раздел «Рейтинг»: топ блогов, топ компаний, темы, рекомендации |
| Аккаунт и настройки | Вход по почте с паролем или одноразовым кодом, вход через соцсети и Яндекс, привязка аккаунтов, смена почты и пароля, выход со всех устройств, заморозка и удаление аккаунта, онбординг (имя, аватар, выбор тем, уведомления). Настройки: блог, ленты, уведомления, внешний вид (тема светлая, тёмная, системная; шрифт; язык), смена никнейма раз в месяц |
| Модерация | Жалобы с 8 причинами (оскорбление, нарушение закона, порнография, насилие, авторские права, введение в заблуждение, политика, нейроконтент), баны, снятие с публикации, удаление из темы, «убрать из всех лент», скрытие по требованию властей, предупреждение от редакции, правила сообщества |
| Монетизация | Подписка Plus для читателей (без рекламы, бейдж, видеоаватар, час на правку комментария, список оценивших, промокоды, подарок подписки). Тариф Pro для компаний (галочка, кликабельные кнопки, индексация, дополнительные показы, лимит постов, заморозка, счета для юрлиц). Донаты авторам, платные подарки и коллекция, ачивки, продвижение поста за показы, рекламные блоки в ленте и под постом с маркировкой рекламодателя |

Сверх этого на DTF есть сторис и ИИ-ассистент в разделе «Рейтинг»; партнёрские сервисы, мини-игры и конвертер валют в проект не входят.

## 3. Роли и права

В системе 6 ролей; каждая следующая включает права предыдущей. Ролей платных подписчиков и компаний нет: монетизация исключена из проекта.

| Роль | Что может |
| --- | --- |
| Гость | Читать ленты, посты, комментарии, блоги и темы; искать; делиться ссылкой. Любое действие с записью открывает окно входа |
| Пользователь | Писать посты и комментарии, ставить реакции, подписываться, вести закладки и чёрный список, писать в мессенджер, жаловаться, настраивать ленты и уведомления |
| Модератор темы | Убирать пост из темы, закреплять пост в теме, удалять комментарии и ветки в постах темы |
| Модератор платформы | Разбирать жалобы, банить, снимать посты с публикации, убирать из лент, ставить предупреждение от модерации, работать с очередью проверки контента |
| Редакция | Публиковать «материалы редакции» и новости, попадать в виджет новостей, закреплять посты на главной |
| Администратор | Управлять ролями, темами, справочниками, ачивками, настройками платформы |

Ограничения по карме: новый аккаунт и аккаунт с отрицательной кармой не может ставить реакции и создавать темы; забаненный пользователь только читает.

## 4. Функциональные требования

Требования сгруппированы по 16 модулям DTF-паритета; мост с Telegram (FR-TG), единый аккаунт (FR-ID) и правила контента описаны в отдельных документах; код модуля (FR-…) повторяется в эпиках и бэклоге.

### FR-AUTH. Аккаунт и вход

- Регистрация и вход по почте: пароль (минимум 6 символов) или одноразовый код из письма с таймером повторной отправки.
- Вход через внешние провайдеры (Яндекс, VK, Google, Telegram); привязка и отвязка провайдеров в настройках.
- Смена почты и пароля с подтверждением кодом; восстановление доступа.
- Вход по OpenID Connect (ADR-0002), сессии на access и refresh токенах, список устройств, «Выйти со всех устройств».
- Заморозка и разморозка аккаунта, удаление аккаунта с отложенным стиранием данных.
- Онбординг после регистрации: имя (2–30 символов), аватар, выбор тем, включение уведомлений; каждый шаг можно пропустить.
- Лимиты попыток входа и регистрации, капча при подозрительной активности.

### FR-PROFILE. Блог и личная страница

- Шапка: обложка с выбором положения перетаскиванием, аватар, имя, никнейм вида @name или id123, описание, бейджи, статус «онлайн».
- Счётчики подписчиков и подписок со списками.
- Вкладки «Посты» и «Комментарии»; сортировка постов по дате и популярности; закреплённый пост.
- Действия посетителя: подписаться, включить уведомления о новых постах, написать сообщение, заблокировать, пожаловаться.
- Настройки блога: название (до 25 символов), описание (до 160 символов), никнейм (смена не чаще раза в 30 дней, проверка занятости), кто может комментировать, «показывать посты всем», «показывать, когда я онлайн».
- В своём профиле владелец видит дату регистрации и кнопки «Ред.», «Статистика», «Настройки». Личные разделы: черновики, закладки (посты и комментарии), подписки, статистика, ачивки.

### FR-FEED. Ленты

- Три ленты: «Популярное» (ранжирование по «горячести»), «Свежее» (хронология с фильтром по рейтингу: все, от −10, от +5, от +10), «Моя лента» (подписки, сортировка по популярности или дате).
- Топ за день, неделю, месяц, год и всё время; лента «Просмотренные».
- Курсорная пагинация с бесконечной подгрузкой, плашка «Показать новые» при появлении свежих постов, восстановление позиции при возврате назад.
- Карточка поста: автор, тема, дата, заголовок, превью блоков, «Показать полностью», реакции, счётчики, лучший комментарий, меню действий. Короткий пост показывается целиком, лонгрид — с обрезкой.
- Лучший комментарий под карточкой (решение владельца 21 ноября 2026): если у поста есть комментарии, под строкой счётчиков показывается самый популярный из них (по рейтингу, при равенстве — более ранний): аватар, имя автора и первые строки текста с обрезкой многоточием. Нажатие открывает этот комментарий на странице поста. У поста без комментариев блока нет. Во всех лентах и на обеих версиях, десктопе и телефоне.
- Настройки лент: главная по умолчанию, скрывать просмотренные, автопроигрывание видео, контент для взрослых.
- Виджеты: новости редакции над лентой, «Популярные комментарии» в правой колонке.

### FR-POST. Пост

- Типы: пост в блоге, пост в теме, материал редакции, новость, репост с комментарием, пост-ответ на другой пост.
- Адрес вида /тема/id-слаг; слаг строится транслитерацией заголовка.
- Страница поста: блоки контента, плавающая панель действий, реакции, закладка, «Поделиться», счётчики просмотров и репостов, список репостов и ответов, рекомендации под постом.
- Действия автора: редактировать, снять с публикации, удалить, закрепить в блоге, убрать тему, изменить право комментирования, смотреть статистику, продвинуть.
- Меню «…» чужого поста: реакции, пожаловаться, скрыть (донатов, подарков и продвижения, которые есть на DTF, у нас нет). Действия читателя: скрыть из ленты, заблокировать автора, скрыть тему, пожаловаться, скопировать ссылку, написать пост-ответ.
- История версий с просмотром и откатом; пометки «обновлён» и «ещё дополняется».
- Метки: «из Telegram», предупреждение от модерации, соавтор, закреплённый, скрыт по требованию закона.
- Учёт просмотров: показы в лентах, открытия поста, время чтения.

### FR-EDITOR. Редактор

- Быстрый пост (решение владельца 21 ноября 2026): написать пост должно быть так же просто, как твит или пост в Telegram. Над лентой (на телефоне — по кнопке «Написать») есть компактная форма: поле текста без заголовка, прикрепление фото или видео, выбор темы или своего блога и кнопка «Опубликовать». Кнопка «Развернуть» открывает полный блочный редактор для лонгридов и больших статей и переносит в него набранный текст и вложения без потерь. Писать посты может любой вошедший пользователь — в свой блог и в любую тему (ADR-0029).
- Блочный редактор: заголовок поста необязателен (короткий пост), блоки добавляются через «+» и перетаскиваются.
- Блоки для всех авторов (12, как в редакторе DTF): текст, подзаголовки H2 и H3, фото или видео (несколько файлов дают галерею), ссылка, цитата, список, код, разделитель, аудио, опрос, персона; меню блоков с поиском.
- Блоки врезка, предупреждение, спойлер, число, файл, встроенный пост доступны всем авторам (на DTF — только редакции и компаниям); блока «кнопка» нет. Для научных статей добавлены блоки формула (LaTeX), таблица, сноски и список источников. Опрос — обычный и анонимный, с переголосованием. Эмбеды внешних сервисов создаются вставкой ссылки.
- Форматирование внутри текста: жирный, курсив, маркер, ссылка, упоминание @ник, хэштег; всплывающая панель при выделении; поддержка Markdown-сокращений.
- Вставка из буфера и перетаскиванием: картинка становится медиаблоком, ссылка — эмбедом или карточкой.
- Параметры публикации: тема или «без темы», своя обложка, кто может комментировать (все, только подписчики, никто).
- Черновики с автосохранением и индикатором «Сохранено», предпросмотр, валидация (пустой пост, длина заголовка, размер поста и блока).
- Полноценная работа на телефоне: панель блоков над клавиатурой, загрузка из галереи и камеры.

### FR-MEDIA. Медиа

- Изображения: JPEG, PNG, WebP, GIF; хранение оригинала, ресайз и конвертация на лету по параметрам в адресе, размытое превью и доминирующий цвет до загрузки.
- Видео: загрузка MP4, MOV, WebM, транскодирование в несколько качеств, постер, плеер с автопроигрыванием без звука в ленте; GIF конвертируется в видео.
- Аудио и произвольные файлы с ограничением размера и проверкой типа.
- Загрузка по ссылке (сервер скачивает и сохраняет у себя), разбор ссылки в карточку по Open Graph и oEmbed.
- Просмотр: полноэкранная галерея с листанием и масштабом, подписи к медиа.
- Поиск GIF во внешнем каталоге и список избранных GIF для комментариев.

### FR-COMMENT. Комментарии

- Дерево ответов с линиями веток, сворачиванием ветки, подгрузкой длинных веток и отдельной страницей треда.
- Сортировка «Популярные» и «По дате»; подсветка новых с прошлого визита; ссылка на конкретный комментарий.
- Форма: свёрнутое поле «Комментарий…», которое раскрывается при нажатии и показывает ряд кнопок вложений и кнопку отправки; текст с форматированием, упоминания с подсказкой, вложения (фото, видео, GIF), вставка картинки из буфера.
- Действия: ответить, реакция, закладка, редактировать (окно по времени), удалить, пожаловаться, скопировать ссылку, заблокировать автора.
- Автор поста закрепляет один комментарий и удаляет ветки под своим постом.
- Комментарии от заблокированных скрыты с кнопкой «Показать»; удалённые оставляют заглушку, если есть ответы.
- Новые комментарии приходят в открытую страницу в реальном времени.

### FR-REACT. Реакции, закладки, репосты, карма

- Лайк одним нажатием и выбор реакции из набора (анимированные эмодзи) на постах и комментариях; одна реакция от пользователя, смена и отмена.
- Ряд реакций со счётчиками, список оценивших.
- Рейтинг поста и комментария считается из реакций; карма автора — из рейтинга его контента; пороги кармы ограничивают действия.
- Закладки на посты и комментарии с отдельным разделом.
- Репост в свой блог с текстом, список репостов поста; «Поделиться»: копия ссылки, системное меню телефона, соцсети.

### FR-TOPIC. Темы и хэштеги

- Тема (сообщество): название, адрес, описание, аватар, обложка, модераторы, правила. Тему создаёт пользователь с подтверждённой почтой — с лимитом тем на аккаунт и проверкой названия и адреса по стоп-списку и зарезервированным адресам (E11-11, ADR-0084) — или администрация.
- Страница темы: шапка, число подписчиков, вкладки «Посты» и «Комментарии», сортировка, закреплённые посты.
- Подписка на тему, уведомления о новых постах, скрытие темы из лент.
- Хэштеги в тексте поста ведут на ленту тега; подсказка тегов при вводе.

### FR-SUB. Подписки и фильтрация

- Подписка на блоги и темы; раздел «Подписки» с массовой отпиской от блогов, тем или всего.
- Чёрный список пользователей: их посты и комментарии скрыты, сообщения не приходят.
- Список скрытых тем, скрытие отдельного поста.

### FR-NOTIFY. Уведомления

- События: ответ на комментарий, комментарий к посту, реакция, упоминание, новый подписчик, новый пост в подписке, репост, пост-ответ, ачивка, решение модератора, новый пост в привязанном канале Telegram (предложение переноса).
- Лента уведомлений со счётчиком непрочитанных, группировкой однотипных событий, «Пометить все как прочитанные», отпиской от конкретного треда.
- Каналы: внутри сайта в реальном времени, браузерные push, письма; настройка галочками по типам событий для каждого канала (на DTF — 9 типов писем, включая «Интересное за день» и статистику блога, и 8 типов в «колокольчике»).

### FR-MSG. Личные сообщения

- Список диалогов с последним сообщением и счётчиком, поиск диалогов.
- Диалог один на один: текст, вложения, редактирование, удаление, копирование, отметка прочтения, доставка в реальном времени.
- Блокировка собеседника, запрет входящих в настройках, лимит длины сообщения, антиспам для новых аккаунтов.

### FR-SEARCH. Поиск и рейтинг

- Быстрый поиск в шапке с подсказками и историей запросов.
- Поиск открывается внутри раздела «Рейтинг»: поле запроса с «Отмена», ниже блоки «Блоги», «Темы» и «Посты» с кнопкой «Подписаться» в строках и «Показать ещё»; кнопка фильтров у блока «Посты»; фильтры «точное совпадение», «только заголовки», «посты редакции», период, автор; порядок по релевантности или дате.
- Раздел «Рейтинг»: топ блогов с динамикой места, список тем, рекомендованные посты; кнопка «Подписаться» в каждой строке.

### FR-MOD. Модерация и админ-панель

- Жалоба на пост, комментарий, блог или сообщение с выбором причины из справочника и текстом.
- Очередь жалоб для модераторов: фильтры, взятие в работу, решение, уведомление заявителя и нарушителя.
- Санкции: удаление контента, снятие с публикации, удаление из темы, удаление из лент, бан на срок или навсегда, бан в мессенджере.
- Автоматика: стоп-слова, лимиты частоты, детект дублей и спам-ссылок, премодерация первых постов новых аккаунтов.
- Админ-панель: пользователи и роли, темы, справочники, ачивки, очередь проверки контента, журнал действий модераторов, сводка метрик.
- Статические страницы: «О проекте», «Правила», политика конфиденциальности, правила рекомендаций.

### FR-STATS. Статистика

- Статистика поста: показы в лентах, открытия, клики по ссылкам, источники переходов.
- Статистика блога: открытия постов по дням, подписчики, топ постов по открытиям, выбор периода.

### FR-UI. Общий интерфейс

- Темы оформления: светлая, тёмная, системная; выбор шрифта и сглаживания; язык интерфейса.
- Уведомления-тосты, скелетоны загрузки, состояние «нет интернета», страницы 404 и «доступ закрыт», кнопка «наверх», баннер согласия на cookie.
- Горячие клавиши на десктопе, доступность с клавиатуры и для экранных дикторов.

## 5. Десктопная и мобильная версии

Одно адаптивное веб-приложение с четырьмя раскладками; границы взяты из стилей DTF (640, 925 и 1240 px).

| Ширина окна | Раскладка | Навигация |
| --- | --- | --- |
| от 1240 px | Три колонки: левое меню 220 px, лента 640 px, правая колонка виджетов 320 px (замерено на DTF при ширине окна 1440 px) | Левое меню постоянно видно, шапка с поиском, «Написать», уведомления, аватар |
| 925–1239 px | Две колонки: левое меню и лента, правая колонка скрыта | Как на широком экране |
| 640–924 px | Одна колонка с полями | Нижняя панель вкладок, левое меню скрыто |
| до 639 px | Одна колонка во всю ширину, карточки без скруглений по краям | Нижняя панель из 5 вкладок и плавающая кнопка «Написать» |

**Десктоп.**

- Левое меню: «Популярное», «Свежее», «Моя лента», «Сообщения», «Рейтинг», список тем с «Показать все», ссылки «О проекте», «Правила», переключатель темы оформления.
- Правая колонка: «Популярные комментарии», «Интересные блоги»; колонка прилипает при прокрутке. Шапка: логотип, кнопка поиска (по нажатию поле раскрывается на ширину ленты, страница затемняется), «колокольчик» с выпадающей панелью уведомлений, «Написать», аватар с меню (профиль, черновики, закладки, коллекция, донаты, тема оформления, настройки, выход).
- Пост открывается на той же странице с кнопкой «назад» в шапке и плавающей панелью действий внизу; позиция ленты сохраняется.
- Редактор открывается окном 800×700 px поверх размытой ленты: вверху автор и выбор темы, справа кнопки «развернуть на весь экран» и «закрыть», внизу кнопка «Опубликовать». Сообщения открываются в центральной колонке, левое меню и правая колонка остаются на месте.

**Мобильная версия.**

- Нижняя панель: «Лента», «Рейтинг», «Уведомления», «Сообщения», «Меню»; счётчики непрочитанного на иконках.
- Экран «Меню» заменяет левую колонку: профиль или вход, черновики, закладки, коллекция, подписка, настройки, тема оформления, служебные ссылки.
- Ленты переключаются вкладками под шапкой; шапка прячется при прокрутке вниз и возвращается при прокрутке вверх; обновление жестом «потянуть вниз».
- Комментарии: уменьшенный отступ веток, глубокие ветки открываются отдельным экраном, форма ответа прижата к клавиатуре.
- Меню действий и выбор реакции — нижние шторки; выбор реакции по долгому нажатию; галерея листается свайпом, масштаб щипком.
- Редактор и диалог — полноэкранные экраны; учёт «чёлки» и безопасных зон, минимальный размер нажимаемой области 44 px.
- PWA: установка на домашний экран, push-уведомления, кэш оболочки, баннер «В приложение».

## 7. Архитектура и модель данных

Модульный монолит на ASP.NET Core с отдельными фоновыми воркерами и клиент на Nuxt 3 с серверным рендерингом; стек утверждён владельцем продукта 19 ноября 2026.

| Компонент | Технология | За что отвечает |
| --- | --- | --- |
| Веб-клиент | Nuxt 3 (Vue 3, TypeScript), PWA | Серверный рендеринг, адаптивный интерфейс, редактор блоков |
| API | ASP.NET Core, REST с версиями, OpenAPI | Вся бизнес-логика, модули по областям из раздела 4 |
| Реальное время | SignalR (WebSocket) | Новые комментарии, уведомления, сообщения, счётчики |
| Основная база | PostgreSQL | Пользователи, посты (блоки в JSONB), комментарии, подписки |
| Кэш и очереди | Redis, RabbitMQ | Кэш лент и счётчиков, лимиты частоты, фоновые задачи |
| Поиск | OpenSearch | Полнотекстовый поиск с русской морфологией, подсказки |
| Медиа | S3-хранилище, imgproxy, FFmpeg-воркер, CDN | Хранение оригиналов, ресайз на лету, транскодирование видео, раздача |
| Аналитика | ClickHouse | Просмотры, показы, статистика постов и блогов |
| Воркеры | .NET-сервисы на очереди | Рассылка уведомлений, пересчёт «горячести» и кармы, индексация, почта, push |
| Админ-панель | Отдельное приложение на Vue 3 | Модерация и управление платформой |
| Инфраструктура | Docker, Kubernetes или Compose на старте, GitHub Actions | Сборка, выкладка, окружения dev, stage, prod |

**Ключевые сущности.** User и Session; Subsite (блог пользователя или тема — одна сущность с типом, как на DTF); Post, PostVersion, Draft; Block (внутри поста); Media; Comment; Reaction; Bookmark; Subscription; Mute и Block; Notification и NotificationSetting; Channel и Message; Hashtag; Complaint, Ban, ModerationLog; Achievement; ExternalChannel, ExternalPostLink, GuestComment (мост с Telegram); Account и ExternalIdentity (модуль Identity); StatEvent.

**Принципиальные решения.**

- Пост хранится как упорядоченный массив типизированных блоков в JSONB; схема каждого блока валидируется на сервере, неизвестный блок клиент показывает заглушкой.
- Дерево комментариев — ссылка на родителя плюс материализованный путь, чтобы ветка читалась одним запросом.
- «Моя лента» собирается при чтении по подпискам с кэшем; «Популярное» — из очков «горячести», которые воркер пересчитывает по реакциям, комментариям, просмотрам и возрасту поста.
- Счётчики ведутся в Redis и периодически сбрасываются в базу; сырые события просмотров уходят в ClickHouse.
